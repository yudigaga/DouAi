# DouAi 0.2.60：用户目录、设置保存与组件透明度

长期签名 R8 Release **0.2.60 / 161**，包名 `io.github.yudigaga.douai`。GitHub `v0.2.60` 与 LSPosed `161-0.2.60` 每端仅附同一 APK；覆盖安装后彻底重启抖音。

## 累计更新

- 用户资料和各处选择器统一为聚合目录，显示真实昵称、头像及抖音号；支持资料补全、原生用户搜索和“全部 / 未关注 / 我关注 / 关注我”筛选，保留搜索与勾选。关系读取失败时不把未知用户当作未关注。
- 自动化名单统一“全部 / 仅名单内 / 排除名单内”，刷新后更新资料与关系。普通开关即改即存，文本、多选及有保存按钮的窗口保留草稿；取消或返回不写入。设置按明确依赖显示，共享管理入口保留。
- 自定义组件增加独立透明度，固定项与自定义滑块支持轻点或点击数值输入 `-2～255` 的整数。旧规则保留 `-2` 的移除效果；自定义项遵循暂停全显示、恢复播放重新应用及手势设置，修复外层容器、多窗口恢复和连续方向键调节的焦点保持。
