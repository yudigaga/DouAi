# DouAi 0.2.71：播放阅读工具与画面过渡修正

正式版 **0.2.71 / 172**，长期签名 R8 Release，安装后彻底重启抖音。主仓源码标签为 `v0.2.71`，LSPosed 发布标签为 `172-0.2.71`。

本版汇总 0.2.67 至 0.2.71 的变化：

- 抖音 41 增加后退/快进 10 秒、时间点书签、章节和字幕搜索；阅读入口可配置到九宫格手势与首页侧栏。书签按账号本地保存，增加作者、文案和封面，暂停跳转不主动播放。字幕只读取宿主已有轨道，首版支持 WebVTT，不识别画面内嵌文字。
- 已加载评论查找、评论工具及语音转写统一使用 Miuix 界面，可手动通过宿主逐页加载评论并更新结果。查找限已加载正文与已展开回复，转写只使用宿主已有文字，不上传音频识别；不自动遍历全部评论。
- 增加默认关闭的“减少已看作品”，仅记录当前账号在主推荐页实际显示的作品，保留期可选 1/3/7 天，默认 3 天；关闭即停采停滤，记录不随配置备份导出。
- 0.2.70/0.2.71 修正“隐藏上下黑边”的画面取景及切卡、过渡遮罩闪烁：按可见区域等比居中，旧卡完全离屏后归还缩放；手动滑动沿用原生连续滚动，自动切换缺帧时回退原生动画。实际流畅度仍受宿主、网络、解码与屏幕合成时序影响。
