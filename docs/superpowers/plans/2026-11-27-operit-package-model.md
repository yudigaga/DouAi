# DouAi 技能与工具包重构

基线为 `d6ee3c1`。参考 Operit 的包目录与按需加载方式，在 AI 联系人和工作 AI 使用同一入口。

1. **文档 Skill**。按 `SKILL.md`、`name` 和 `description` 的目录约定导入本机文档。设置可预览、启停和删除。`/文档技能` 可编写同样的 Markdown，确认后安装为停用。导入与列目录只读取本机资料。选用后加载完整正文，可另外读取一份所选包的参考文档。
2. **包目录**。列出文档 Skill、已授权的 MCP 服务和内置工具。显示名称、说明和类型，使用带类型的稳定 ID 处理重名。聊天可打开目录或使用 `/use_package`。模型选包只读名字和说明。
3. **工具执行**。内置工具复用现有命令。MCP 包在明确选用时发现工具，显示受校验的工具名称与说明。可手动填参数，也可让模型根据本轮任务和已公开的标量参数定义提出一次调用。提交前确认参数，沿用现有 HTTPS、凭据、服务授权和远端参数校验。用户取消、服务变化或授权撤销时不执行。
4. **回归**。覆盖导入、目录读取时零网络、选中后读取正文、MCP 发现与调用隔离，以及两个聊天入口。使用合成素材与本机测试替身。保留原来结构化技能、斜杠命令、服务配置、授权和在途任务。

本轮沿用 DouAi 的受控能力与远程 HTTPS MCP。导入包中的脚本作为文件预览。无需在抖音宿主里启动本地 MCP 进程或加载任意插件程序。
