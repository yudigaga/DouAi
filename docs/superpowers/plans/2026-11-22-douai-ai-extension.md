# DouAi AI 扩展实施计划

基线为 DouAi 0.3.1 `51a04f8`。仅在 `codex/ai-extension` 工作树提交候选。每阶段记录变更范围、专项测试和待独立验收事项。

1. 两个用户发起入口显式接入 `AiTestChatDialog.enableSkills`。共享 `AiSkills` 匹配命令和执行。斜杠菜单按输入过滤，测试摘要、模拟查询、未知命令、普通对话和附件隔离。复用聊天停止与结果丢弃逻辑。
2. 在模型设置提供生成、试跑、停用和回退。模型只产生受约束的清单及声明式执行定义。先用纯文本和模拟服务试跑，发布时一次替换包含两个文档的版本快照。服务登记、凭据保管、授权快照及预算由宿主控制。
3. 在模型设置提供 HTTPS Streamable HTTP 服务预览、导入、授权发现和绑定。沿用网络层。导入清空授权，端点或工具定义变化触发重审，处理初始化、会话、JSON 与 SSE 响应。
4. 从现有模型列表选稳定 ID，建立隔离的单轮子代理执行。父任务统一截止和取消，工具限于显式白名单和预算，禁止子代理再委派。验证四种模型协议及普通对话行为。

阶段 1 专项测试覆盖两个入口都能使用同一命令、部分输入只展示匹配项、技能分支绕开普通模型会话。阶段 2–4 的专项测试随各阶段候选记入交接文档。
## 2026-11-22 · 文本和图片结果

- 从 `510f197` 接续。将执行结果和服务声明分成文本与图片，原有执行定义按文本读取。
- 图片意图由本地生成路径处理。匹配并重新检查已授权的图片服务，用有效本地图片试跑。缺少匹配时原子保存草稿，重试连接前不进入命令目录。
- 同名已安装技能在预览后由用户确认替换，保留旧版回退。将服务输出类型加入授权匹配。
- 两个聊天入口复用图片渲染和停止行为。用模拟服务验证有效图片、文字和无效图片失败、授权撤销与超时不重发。
## 2026-11-22 · 从对话创建和补齐单条 Skill

- 只拦截两个手动输入区明确的单行创建请求。生成声明并持久保存草稿，通过本地校验的无配置技能直接启用。聊天用真实结果显示缺项，并打开该名称对应的设置项。
- 声明驱动接口地址、模型、凭据及授权状态。表单只为当前草稿配置，密钥由现有本地凭据层处理。适用的现有授权自动复用。
- 补齐并授权后异步对话以外的本地事务试跑和启用。已有同名版本等显式确认。独立草稿配置避免回退时丢失旧版本的凭据绑定。
- 覆盖聊天创建、同名与待配置状态、设置直达、闭环调用和凭据隔离。使用模拟模型或本地样图验证。
## 2026-11-23 · 聊天模型编写和修订 Skill

- 手动输入区把明确的编写、修订、内置和一次性编写并内置请求区分开。使用当前对话已配置的模型做隔离单轮请求，修订只带上一份已验证草案。
- 用严格的版本 3 声明接收本地摘要、自定义指令文本和已有图片服务。已有版本 1/2 按原约定执行。只保存用户明确内置且仍属于当前对话的草案。
- 复用原有缺项、授权、同名确认和原子发布流程。自定义指令文本仅调用当前对话模型，不具备工具、任意执行或自定义网络目标。
- 使用模拟模型、服务和两个真实 UI 入口夹具验证创建、修订、内置、重开、回退、取消、普通对话及错误边界。
## 2026-11-23 · 逐条删除自定义 Skill

- 详情显示删除操作与二次确认。确认携带所见记录的版本、待连接草稿和身份，旧确认不能作用于新记录。
- 一次原子索引更新移除该名称、全部版本及关联草稿。已移除版本目录按本机技能库的所有权边界清理，失败可重试。
- 删除成功后刷新现有设置和已打开的两处命令菜单。排队命令与待连接重试按原记录的稳定身份复核。
- 验证确认、取消、纯草稿、同名草稿、重开、已批准的服务留存、菜单和陈旧请求。
## 2026-11-23 · 编辑单条 Skill 与明确生图请求

- 从单条详情编辑说明与可用的文本指令。保存前复核完整原记录，保存为原命令名下的待确认新版。用户确认才切换，保留回退。
- 图片新版可从同一详情补地址、模型、密钥和授权。沿用原授权仅限原服务绑定，新的专用配置走既有本地凭据和授权流程。
- 明确的单数、复数与中文创建请求进入 Skill 作者模式。明确生图请求需要图片输出声明，模型返回文本时显示类型不符，避免安装错误技能。
- 验证手机原句、两入口、缺项、编辑取消、确认、回退、旧格式、删除和同名并发冲突。
## 2026-11-23 · 图片服务模型目录与密钥保存

- 固定基线先复现已经启用的模拟图片 v1，经编辑、保存草稿和配置图片服务进入 OpenAI Images 表单。分别核对端点、格式、凭据层、登记与授权。
- 目录请求由用户主动触发。只走明确同源 HTTPS 的 GET，使用本次输入或当前草稿对应生图绑定中本地保存的密钥。模型目录与生图地址分别验证。
- 选择模型仅填入表单，手填继续可用。配置可部分保存，凭据只在成功或关闭时清空表单，错误显示真实阶段，授权及启用新版各自确认。
- 用合成响应覆盖查询、选择、同源校验、保存、重开与旧版。将未复现的手机错误边界单列到交接记录。
## 2026-11-23 · 图片服务与 AI 供应商填法对照

- 用实际 AI 和单技能表单复现相同基础地址的差异，检查保存标志、目录请求地址及旧版本。
- 以用户填写的基础地址解析固定生图地址与同源模型目录，完整模式保留旧自定义地址。凭据层按已解析的生成目标绑定。
- 复用模块 Miuix 密码控件，保存前校验密钥的加密读取。重开显示已保存状态，输入保持空白。
- 用合成密钥、目录响应、双表单与失败路径回归。证据区分本地复现与手机未知原因。
