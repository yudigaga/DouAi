# DouAi AI 扩展实施计划

基线为 DouAi 0.3.1 `51a04f8`。仅在 `codex/ai-extension` 工作树提交候选。每阶段记录变更范围、专项测试和待独立验收事项。

1. 两个用户发起入口显式接入 `AiTestChatDialog.enableSkills`。共享 `AiSkills` 匹配命令和执行。斜杠菜单按输入过滤，测试摘要、模拟查询、未知命令、普通对话和附件隔离。复用聊天停止与结果丢弃逻辑。
2. 在模型设置提供生成、试跑、停用和回退。模型只产生受约束的清单及声明式执行定义。先用纯文本和模拟服务试跑，发布时一次替换包含两个文档的版本快照。服务登记、凭据保管、授权快照及预算由宿主控制。
3. 在模型设置提供 HTTPS Streamable HTTP 服务预览、导入、授权发现和绑定。沿用网络层。导入清空授权，端点或工具定义变化触发重审，处理初始化、会话、JSON 与 SSE 响应。
4. 从现有模型列表选稳定 ID，建立隔离的单轮子代理执行。父任务统一截止和取消，工具限于显式白名单和预算，禁止子代理再委派。验证四种模型协议及普通对话行为。

阶段 1 专项测试覆盖两个入口都能使用同一命令、部分输入只展示匹配项、技能分支绕开普通模型会话。阶段 2–4 的专项测试随各阶段候选记入交接文档。
