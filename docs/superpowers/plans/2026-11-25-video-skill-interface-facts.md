# 从接口资料生成视频技能

基线为 7b621a7。显式创建命令的需求行交给当前模型生成技能名称和说明，接口资料留在本机校验。DouAi 从用户提供的接口事实或明确关联的已配置视频技能生成可执行声明。模型提出的接口和配置字段须经本机替换与验证。

缺少协议事实时保存待配置草稿并显示具体缺项。用户从同一技能详情补充资料，服务配置沿用 HTTPS、独立凭据和逐次调用确认。嵌套 JSON 字段只遍历有界对象属性，查询仍核对原任务 ID。

用相同的自然语言需求分别验证完整接口资料和缺查询状态字段，再从技能详情补齐、关闭重开并核对原草稿。验证覆盖凭据隔离、旧配置表单及零视频请求。真实接口供应商由用户选择。

接口资料可跟在创建需求下一行。逐项写明提交、提示词字段、提交响应 ID、查询、查询响应 ID、状态字段、状态映射、取消和下载。可以用 data.id 或已知 JSON 回包示例说明嵌套字段。文档规定的普通必填项可用「必填文本字段：model 模型名」等行描述；服务密钥在配置页单独填写。若已有配置可写「沿用技能：命令名」。
