# DouAi 声明式 Skill 与聊天选用

在 `56db833` 上实现。Manifest 4 保留兼容读法。可选 `http.version: 1` 描述字段映射，地址建议只作设置草稿，实际地址与凭据由用户在技能详情保存。视频额外声明同源的查询、取消和下载路径，以原任务 ID 为唯一动态路径参数。真实 HTTP 复用证书、主机名、实际地址检查。任务发出后结果未知时保留本地操作状态。

聊天只向当前模型提供当前可运行的技能名称、能力说明、非敏感字段标签。点名、模型选择和斜杠都在本机核对实际启用版本，再走同一执行路径。对外发送前确认实际目标、字段和值。视频状态和下载复用已确认的同源任务合同，取消有独立确认。

验证从两处聊天入口发起，覆盖缺项、旧版本、歧义、停用、取消确认零外部请求、固定字段映射和视频原 ID 持久化。网络测试只使用受控本地端点，交付局限于本地源码候选。

## 接口范围

`http.request` 将本次文字 `argument` 和已保存且经过类型校验的 `config.<键>` 映射为 JSON 字段。`http.response` 是响应对象的顶层字段。文本取字符串，表格取现有的 `columns` / `rows` 对象，图片取可解码的 Base64。视频提交字段返回任务 ID，查询响应必须回显同一 ID 和已声明状态。视频查询、取消和下载使用已确认地址的同源路径，动态部分只接受完整的 `{id}` 路径段。当前下载合同为直接返回 MP4，每个文件限 16 MiB。

不点名的手动聊天任务最多选择一条技能。路由请求只使用本次文字和有限的可用目录，参数必须来自原文。纯本机验证、列菜单、打开技能详情和关闭调用确认均不会发出技能服务请求。

## 复测入口

- 在「工作 AI」发送「请调用『技能显示名』：原稿」，核对点名、歧义、旧版和停用提示。在「AI 联系人」发送适用的任务但不点名，核对模型只能从当前启用目录选一条，且原始消息和执行结果能保留在当前对话。
- 从聊天创建有必填数字项的外部技能，在技能详情先保存一部分再补齐。核对建议地址保存前未绑定、确认显示类型化字段和值，取消后外部请求计数为零。再确认一次，核对只发出一次写请求。
- 从聊天创建声明了提交、查询、取消和下载的视频技能。核对提交确认、按原任务 ID 恢复、单独取消确认、结果不明时无自动重发、以及完成后从验证过的本机文件播放。
