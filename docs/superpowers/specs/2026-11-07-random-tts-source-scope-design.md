# 大随机来源范围

用户明确要求自定义大随机的“来源范围”。继续采用每次合成自动随机，不增加音色级白名单。

- 大随机模式下显示“来源范围”，可多选系统引擎、第三方、MiniMax、Breeze Blue、Fish Audio。
- 默认全选，兼容现有大随机配置；至少保留一个来源。取消编辑不保存，确认后立即生效，重开恢复。
- 大随机先在勾选且当前可用的来源中等概率抽来源，再抽音色。勾选不等于可用，原有目录、鉴权、单音色和离线语言资格仍需满足。
- 未勾选的来源不参与，全部所选来源都不可用时明确提示，不越过范围选择其它来源。取消系统引擎后不初始化系统音色检查。
- 关闭和小随机不受此范围影响；切换模式保留范围，保存范围停止当前试听。试听与手动/自动语音共用同一请求快照。
- 范围保存在独立配置键并参与备份/导入；非法、未知或空列表导入应拒绝；异常存量配置不得静默扩成全部来源。

实现沿用现有多选对话框和随机选择器。测试覆盖范围过滤、无可用来源、不初始化已排除的系统引擎、配置往返、设置持久化和试听。不构建 APK，不继续正式发布验证；已预留的 0.2.39 / 140 留待后续构建。
