# 长按倍速持续选择与全区域原生拦截

用户明确的行为是：启用“拦截系统长按手势”后屏蔽视频九宫格所有区域的原生长按；右下角配置“倍速”，第一次长按使用模块倍速值，松手与切换视频不恢复，下一次长按才恢复 1 倍。手动选择持续到再次操作或关闭模块。

此前实现把选择附着在当前 holder、作品和播放器，切页、暂停或 root 失活会调用恢复并清空开关；同一 holder 被复用时又可能直接跳过重新应用。这与持续选择的目标不一致。

## 实现

| 情形 | 行为 |
| --- | --- |
| 首次操作倍速 | 建立持续选择，按模块 `playback_speed` 设置速度。 |
| 松手、切视频、复用 holder、更换 manager、返回前台 | 保留选择；新播放器的设置、播放与恢复入口继承当前选择，选中回调也重新应用。 |
| 再次操作倍速 | 选择改为 1 倍，后续视频继续保持 1 倍，自动倍速不会立即覆盖这次手动选择。 |
| 更改模块倍速值 | 已开启的手动倍速同步更新；已关闭的手动选择继续为 1 倍。 |
| 关闭模块 | 解除持续选择，按各播放器独立记录的基线清理，不覆盖已确认的外部速度变化。 |
| 开启原生长按拦截 | 所有九宫格区域暂存 DOWN 并绑定祖先检测器；已配置模块动作仍执行，未配置区域消费长按。短按与滑动重放原始事件后交回宿主。 |

持续选择不强持有播放器；原始速度分别保存在弱引用映射，避免跨引擎串用恢复值。配置刷新先更新手动选择，再由播放层更新已见播放器。暂停视图查找仍依据自己的暂停快照，不能把全区域拦截中的正常播放误认为暂停。
