# 模块独立倍速与预设选择

2026-10-29，本轮用于 DouAi 0.2.33 / 134。按用户要求，模块提供固定倍率，并增加默认 1 倍、长按切换、跨视频保持的控制方式。变更范围为设置、配置迁移、手动目标生命周期和提示；继续使用 0.2.32 已有的 SDK 保护与宿主规则。

## 使用

在“自动播放”打开“仅模块控制倍速”，再在“倍速数值”选择档位；在“长按事件”将右下角设为“倍速”。安装新包后完全结束抖音进程再打开。

固定七档为 **0.75x、1x、1.25x、1.5x、2x、3x、4x**，默认 2x，不再提供自定义数字输入。

| 当前选择 | 长按配置了“倍速”的区域 | 切换视频或播放器 |
| --- | --- | --- |
| 模块正常播放 1x | 采用所选预设 | 保持 1x |
| 模块预设已启用 | 回到模块 1x | 保持所选预设 |

开启该模式时自动启用两项原生长按拦截，九宫格未分配模块动作的区域也不执行原生长按。短按与滑动继续交回原生流程。“自动倍速播放”暂时不可操作，原开关值保留；关闭模式后恢复原来的设置选择，并释放该模式的倍速归属。该模式默认关闭。

修改预设时，已启用的目标立即更新；当前为模块 1x 时保持 1x，直到下一次长按。热开启模式会从现有手动选择转为模块 1x，复用旧的速度会话，让尚在排队的普通手动 SDK 倍速请求读取新的目标；恢复请求保留原有恢复语义。

## 配置与反馈

`PlaybackSpeedPresets` 同时供 UI、运行时和配置导入导出使用。旧自定义数值映射到最近的预设，等距选择较低档，例如 2.75→3、3.5→3、1.75→1.5；非数字或非有限值使用默认 2。仅打开设置页不修改原值，实际选择或应用导入后保存规范值。原生播放器基线及读回数值不做该归一。

`module_only_speed` 影响 PLAYBACK、GESTURE、HOST_BEHAVIOR 三类刷新。有效的原生拦截值来自“原设置或该模式”，不会覆盖用户保存的两个原开关。配置备份的导入预览仍保留原始快照，应用时检查冲突。

设置接受后的 Toast 为“倍速锁定目标：Nx”或“已选择正常播放：1x”。读回与目标不一致、不可用或恰好相等，继续分别记录为 UNCONFIRMED、UNCONFIRMED、SUCCESS，不再用异步 Toast 提示用户重复切换。setter 抛错仍提示设置失败。目标提示不表示已经测得对应物理播放速度。

| 证据 | 可支持的结论 | 位置 |

| 用户提供的 0.2.32 日志，8 次手动操作按 2→1 交替；开启读回 1.7、关闭读回 1 | 请求选择与读回状态不同，“请重试”可能导致用户再次切换为关闭 | `work/gesture-toast-20261029/log/analysis.md` |
| 修改前两个红例分别实际失败 | 旧实现会覆盖目标提示，且独立模式首次选择未固定到 1 | `repro-before.xml`、`exclusive-repro-before.xml`，位于同一 work 目录 |
| 本轮 9 个 suite、210 项相关检查零失败/错误/跳过 | 固定档位、迁移、目标生命周期、旧排队 token、Native/Miuix 与帮助的本地合同通过 | `work/gesture-toast-20261029/module-speed-results/` |

控制路径为设置快照 → `LocalOptions` → `FeedGestureToolsHook.syncModuleOnlySpeedMode` → 全局 `GestureSpeedOverride` → 既有播放器/SDK 保护。初始目标为 1；手动切换和配置更新改变会话目标；选择/恢复视频重新提交该目标。实际引擎读回只用于诊断，不反过来选择模块倍率。

本机抖音 40.8.0 APK 中 `LX/03V6` 提供原生菜单的六个默认值 0.75、1、1.25、1.5、2、3；`long_press_panel_speed_optimize2` 可替换该列表，原生长按默认 2 倍另有路径。因此不能把六个默认值当作所有设备必定相同的菜单。只读摘录在 `work/native-speed-options-20261029/`。

## 验证边界

210 项为相关专项，包含整类配置/播放/手势检查，以及按方法选择的 Native/Miuix 设置检查，未运行完整测试集。正式 APK、Lint、签名及打包合同结果见 [0.2.33 构建记录](release-0.2.33.md)。本轮没有修改两版规则资产或 SDK 保护，不重新将旧版双宿主扫描计入通过数。

用户“修改有效”的实机反馈对应 0.2.32。本轮未进行真机、真实 LSPosed、模拟器或物理播放速度测量，特别是 4 倍的实际速度仍需用户设备复测。保留原日志的 1.7 和未确认结果，不将它们改写成物理 2 倍成功。
