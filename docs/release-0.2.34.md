# DouAi 0.2.34 正式版：按功能选择模型与任务隔离

版本 **0.2.34 / 135**，2026-10-29 本地构建。模型设置改为配置保存，快捷菜单支持按功能选择模型，并修复全局模型变化误取消独立自动化任务。GitHub 标签为 [`v0.2.34`](https://github.com/yudigaga/DouAi/releases/tag/v0.2.34)，LSPosed 标签为 [`135-0.2.34`](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/135-0.2.34)，两端发布同一份原签名 APK 与校验文件。

## 使用与变化

“AI 模型设置”只添加、编辑、保存与删除配置，移除模型启用操作，编辑器统一显示“保存”。保存配置保留已有全局默认和各功能的选择；首次添加也不自动设为全局默认。

长按快捷菜单“切换模型”先选择功能，再选择已保存配置：

- 全局默认。
- 自动回复，私聊、群聊和评论自动回复共用。
- 自动评论。
- 本地数据分析。

后三项可以选择“跟随全局默认”，也可独立选择；一次只修改对应功能。返回不保存，关闭后的旧点击及已删除配置不会静默改选其他供应商。已有自动回复、自动评论和分析页的模型选择保留。

三个自动化 Hook 改为比较本功能绑定及实际选中的完整配置。独立绑定没有变化时，切全局默认、保存其他模型不会取消其请求；修改本功能绑定或其选中配置仍使用原有取消流程。配置格式及接口、密钥、流式、提示词、语音与原生发送流程保持原语义。详细设计与红例见 [模型选择记录](2026-10-29_model-routing.md)。
