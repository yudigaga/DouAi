# DouAi 0.2.27 本地正式构建

2026-10-27，本版修复 Fish 与 Breeze 的 TTS 音色目录获取、浏览和选择。

## 已确认的问题与修复

Fish 官方公开目录能返回有效音色，但旧代码把 `window_limited=true` 当成整次失败。本版保留有效页面，明确显示窗口与总数状态，按服务端 `has_more` 加载更多。未设置范围时默认公开音色；公开浏览允许空 Key，明确保存的“我的音色”范围及其独立 Key 要求保留。

Breeze 新详细日志有 21 次 HTTP 200 和完整响应读取，随后在累计第 2049 个有效唯一音色时命中本机 2048 项上限并丢弃整份目录。对应 0.2.26 的封存源码哈希、R8 mapping ID 和报错行已精确核对。本版使用 Breeze 自己的 `has_more`、cursor/page、筛选和鉴权：首屏即可选择，后续显式加载。达到 2048 项预算或下一页失败时保留已加载音色及当前选择，并提示缩小筛选。目录每次请求使用 45 秒绝对截止，关闭或切换配置后拒绝旧回调。

两家目录状态独立。语音生成正文、音频参数、业务重试和发送回退不在本轮改动范围。详细证据见[目录修复报告](2026-10-27_fish-catalog-window-fix.md)、[Fish 配置](fish-speech.md)和[Breeze 配置](breeze-speech.md)。
