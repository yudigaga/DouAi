# DouAi 0.3.2（203）

本页记录待本地归档的源码候选。正式下载仍见 [0.3.1 发布记录](release-0.3.1.md)。

- 更新「关于 → 帮助」中的离线说明，覆盖设置、侧边栏和手势、自动化、文件导入导出及 AI 扩展。
- AI 联系人与工作 AI 共用 Skills。可在聊天用 `/技能` 编写、编辑原草稿并根据可核对的资料回填，明确内置后再按需配置和授权。输出支持文字、表格、图片和已配置接口的视频任务。
- 图片 Skill 支持独立服务配置和模型目录。视频 Skill 按原任务 ID 查询状态，已保存的任务和成片可在原会话恢复。会话支持复制单条原文，已保存的图片可打开大图、缩放和拖动。
- 扩展功能提供在线 MCP，支持本机登记、JSON 导入导出、授权、发现工具、工具包调用和绑定手动命令。删除服务经二次确认，只移除该服务的本机配置、密钥、工具目录及关联命令。
- 工作 AI 可使用已配置的子代理。子代理仅使用所选的现有模型，执行范围由本机配置决定。
- 抖音 41 的竖屏完整铺满时，符合条件的顶部补色层轻微下移仍保持隐藏。宿主布局重置后，在绘制前恢复等比取景。

具体入口、所需配置及限制见[功能帮助](help.md)。签名 APK、归档摘要及验收范围待本次本地构建记录，前一正式版的验收结果只适用于原 APK。
