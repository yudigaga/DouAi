# DouAi 0.2.64：个人内容年志

长期签名 R8 Release **0.2.64 / 165**，包名 `io.github.yudigaga.douai`。GitHub `v0.2.64` 与 LSPosed `165-0.2.64` 每端仅附同一 `DouAi-0.2.64.apk`。覆盖安装后彻底重启抖音。

## 使用与更新

在「抖音设置 → DouAi → 扩展功能 → 本地数据分析」查看个人内容年志。已有记录先展示本期发现，再看内容版图、一天里的节奏、主动操作及前后期变化；「记录设置与刷新」管理采集，「查看全部统计」保留旧明细。记录默认关闭，主动请求 AI 时才发送分析摘要。

- 「全部」包含首次浏览之前单独发生的 AI 探索。重复点击分别记录，只有同会话内确认相邻的阶段才连线；旧记录不补画未知顺序。
- 记录缺口按日期与来源限制比较，旧数据只有累计丢失数时保留不确定性。操作率分享文字带上话题、操作、实际日期、n/N 和片段单位；模型解读不完整时沿用本地事实。
- 手机、PNG 和分页 PDF 使用同一报告快照。同话题共用色系，并列名次同高显示；修正图形与图例分页，副标题跟随内容。旧统计首次展开时才构建，刷新或换范围使用当前快照。

**升级边界：**数据库为 SQLite v4，分析备份导出为 v3，仍支持旧 v1/v2 分析备份导入。不要用旧版程序直接打开新版数据库。报告描述本地保留记录，不据此推断因果、人格或完整使用经历。
