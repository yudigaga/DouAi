# DouAi 0.2.30 本地正式构建

版本 **0.2.30 / 131**，2026-10-28 本地构建。本版继续处理用户在 0.2.29 中反馈的长按倍速未持续生效问题。没有创建远端标签或上传 Release。

倍速长按现在从 DOWN 暂存输入，并将当前触摸控件父链上实际取得的原生手势检测器绑定到该次手势。已确认的长按消费后续输入，避免祖先容器再次初始化原生识别；短按或滑动则依原顺序回放子控件及检测器各自收到的 DOWN，再交回后续事件。取消、丢失 UP 和重复尾事件均单独清理，不影响未配置区域。

效果确认改用 `RealVideoPlaySpeed`。原 `VideoPlaySpeed` 返回缓存请求参数；参数为 2 倍不代表实际引擎已经确认。真实命令无效或返回 `-1` 时保留未确认结果，不使用请求值冒充成功。恢复基线、自动倍速、暂停视图查找和其它手势保持各自用途。
