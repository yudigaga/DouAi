# DouAi 0.2.33 正式版：模块独立倍速与固定预设

版本 **0.2.33 / 134**，2026-10-29 构建并发布。新增“仅模块控制倍速”及固定倍率选择，修正倍速目标已接受后仍提示“请重试”的反馈。GitHub 标签为 [`v0.2.33`](https://github.com/yudigaga/DouAi/releases/tag/v0.2.33)，LSPosed 标签为 [`134-0.2.33`](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/134-0.2.33)，两端使用同一份原签名 APK。

## 相对 0.2.28 的累计更新

- 修正将 FPS 指标当作倍速读取的问题，改用实际引擎速度读回并区分目标、转发与未确认状态。
- 补足从手势开始阶段接管原生长按的路径，短按和滑动仍交回原生流程；手动选择跨视频保持，再次长按回到 1 倍。
- 为 SDK 异步队列、缓存跳过、播放器更换及原生 option 60 写入补充具体对象归属保护，保留其它选项和恢复请求的语义。
- 新增默认关闭的模块独立模式、固定七档及旧值迁移，修正目标已接受后被异步“请重试”覆盖的提示。

0.2.29 至 0.2.32 的独立产物及验证范围保留在各自记录；历史测试与用户对 0.2.32 的反馈不算作本版执行或设备验收。

## 使用与变化

“自动播放 → 倍速数值”提供 **0.75、1、1.25、1.5、2、3、4 倍**，默认 2 倍，移除自定义输入。旧值按最近档位读取，等距取较低；配置导入导出统一迁移到预设。

打开“仅模块控制倍速”，再将“长按事件 → 右下”设为“倍速”：初始保持模块 1 倍，长按采用所选预设，再长按回到模块 1 倍，跨视频保持当前选择。模式默认关闭；开启后强制两项原生长按拦截，保留原自动倍速和拦截设置值，关闭后恢复。短按和滑动继续使用原生流程。

提示只表达所选目标，读回不符或不可用仍按原诊断记录，不再提示用户重复长按。实际 setter 失败仍提示失败。本轮保持 0.2.32 的 SDK 保护与两版规则资产，详细语义和证据见 [模块独立倍速与预设选择](2026-10-29_module-speed-controls.md)。
