# DouAi 功能帮助

本文与 DouAi 的内置帮助同步。入口：设置主页 → 关于 → 帮助。应用内可离线搜索标题、正文及关键词；关于页同时提供 [免责协议](../DISCLAIMER.md)。

## 开始使用与设置生效

### 首次启用

1. 使用 Android 9 或以上设备，并安装支持 libxposed API 102 的 LSPosed。当前适配目标为抖音 40.6.0 / 40.8.0（com.ss.android.ugc.aweme）；40.8 仅支持内部构建 40809900。

2. 安装 DouAi，在 LSPosed 中启用模块，作用域选择抖音。

3. 完全退出并重新打开抖音，从抖音设置中的 DouAi 入口打开主页，再进入需要配置的分类。首次扫描尚未结束时，先等待扫描结果。

4. 主页底部的“关于”可以打开帮助。帮助内容保存在本地，阅读和搜索不需要联网。

### 模块应用与抖音内设置

桌面上的 DouAi 应用用于查看框架连接、扫描诊断和关于信息，也可隐藏桌面图标。功能配置需要在抖音内的 DouAi 设置中完成，配置保存在抖音私有目录。

模块应用的框架连接状态与抖音内功能配置是不同信息；显示连接成功或扫描完成，不代表每项功能已经在实际页面执行成功。隐藏图标后仍可通过 LSPosed 管理模块。

模块界面自动跟随系统深浅色，无需单独设置。抖音固定浅色时，模块页面仍按系统模式显示；主题切换不改动已保存的配置或用户自选颜色。宿主自身因系统配置变化重建页面时，遵循原有页面关闭行为。

### 何时生效

开关和已保存的配置会通知当前抖音进程，多数功能会立即更新，或在下次切换视频、打开页面、收到消息时使用新设置。编辑窗口中的内容通常要点“保存”才会写入。

已经展示过的启动广告、弹窗和已发送内容无法通过改开关恢复或撤回。修改启动类设置后，完全退出并重新打开抖音检查。安装或更新模块、改变 LSPosed 作用域、扫描未适配时也需要重启抖音。

关闭对应自动功能或修改相关配置会取消尚未提交的旧任务；已经进入抖音发送流程的请求仍应到目标页面或历史记录核对结果。

## 查找设置与查看运行原因

设置首页支持搜索 MiniMax、音色、API Key、保存目录、去水印等词，结果显示完整入口路径；点击只打开对应页面，不更改配置。原生和 Miuix 界面使用同一组导航词条。

自动化历史详情在有数据时显示原因、阶段以及排队、媒体、生成、发送确认等待耗时。旧历史缺少的字段保持未知；私信的排队过期、生成超时、额度不足与宿主未确认分别显示。清空历史不清除发送账本。

自动评论与私信在调用宿主前持久保存发送预留；存储失败或账本没有可用空间时停止发送。重启保留未知结果；宿主提交后的回执超时保留未知结果，未知结果后的迟到失败不会释放预留或自动重发。私信保持单任务执行，同会话有序，多会话轮转，排队与执行各有独立的 120 秒预算。

MiniMax 模型与音色刷新失败保留原列表，提示受控的身份、限流、余额、权限或格式原因；服务端原始错误正文不进入提示。高级选项提前标注不兼容原因并保留保存时校验；手填未知模型可保留，但不将其高级能力标为已验证。

## 配置备份：导入与导出

### 导出 JSON 备份

进入抖音内 DouAi 设置的“扩展功能 → 配置备份”，点击“导出配置”，通过系统文件选择器保存 JSON 文件。备份包含本版支持的功能设置、模型配置、提示词、范围名单、组件定位和接口配置，不包含历史记录、发送账本、运行缓存或重试/重置指令。

“导出包含 API 密钥”默认不勾选。默认省略密钥和可能包含凭据的自定义请求头、参数与接口地址片段，导入后可能需要补填。回复正文、提示词等自由文本原样保存，请检查其中手填的敏感信息。勾选包含密钥后文件会明文保存这些字段，请妥善保管。

### 预览并导入

点击“选择配置文件”，读取并校验后核对变更、移除和需补填字段数量。默认合并，保留备份没有包含的当前设置；勾选“覆盖当前配置”会重新计算预览，并移除备份之外的可备份功能设置。运行状态和发送账本不受覆盖操作影响。

只有点击“确认导入”后才应用配置。配置会立即生效，可能改变自动回复、评论等开关；需要重新安装 Hook 的项目需重启抖音。预览后若当前配置已改变，必须重新预览。导入期间不会向运行功能发布尚未成功提交的临时配置，写入失败会尝试恢复原快照。

不含密钥的备份只在模型及接口身份匹配时保留当前凭据；不同服务、账号或无法确认的地址需重新填写。系统目录授权和本地音频文件不会随 JSON 转移，跨设备导入后可能需要重新选择。

### 文件与取消

仅支持 DouAi 格式的 UTF-8 JSON，文件上限 2 MiB；损坏、错型、未知格式版本或不支持的设置键会被拒绝。关闭页面或取消未确认的操作不会导入配置；已明确确认的整批写入允许完成，关闭后不再更新旧页面。导出中断时可能留下不完整文件，请确认导出成功后再使用。

## 本地数据分析

0.1.81 增加本机使用者的人物侧写、历史对照和融合图表：日历、类型构成、话题版图、作者集中度、星期时段热力、话题迁移，以及升级后实际采到的可见片段与动作关联。可选填写使用目的和侧写反馈；它们用于自我校准，不是心理人格分数。详情见 [本地人物侧写](portrait-analysis.md)。

在抖音内 DouAi 设置的“扩展功能 → 本地数据分析”开启记录后统计普通图集、Live 实况图集、短视频、长视频，以及作品作者、话题和已接入的功能实际触发。默认关闭，不补录历史记录；连续重复作品回调合并，切走后重新浏览计新一次。

支持今天、7 天、30 天、90 天和全部保留记录，提供趋势、占比、排行、时段分布与最近记录。长视频按 5 分钟划分，未知类型单列；浏览次数不代表完整观看或观看时长。

数据和开关保存在抖音本地私有的不备份目录，不自动上传。统计默认不纳入配置备份，可在备份页主动选择包含分析数据；采集开关不会随备份恢复。最多保留 365 天。关闭记录保留已有报告；“清空数据”确认后删除统计。

在本地数据分析页的 AI 分析区域打开“模型配置”，可从已有供应商配置中独立选择，默认“跟随全局模型”。本地分析的选择独立于自动回复和自动评论，不改变全局默认模型；显式选择已保存配置时不要求已选择全局默认。选择跟随全局时，先在快捷菜单“切换模型 → 全局默认”选择配置。所选配置被删除后需重新选择，不自动切换供应商。本地分析沿用所选配置的接口、密钥、模型、一级提示词、响应方式（流式或非流式）、推理强度及其他请求参数。

在“二级提示词”填写本地分析专用的关注点或表达要求，留空或点击“恢复默认二级提示词”使用默认分析提示；它不修改模型一级提示词或自动回复、自动评论的二级提示词。例如可填写“重点比较最近一周与前期的内容类型和活跃时段变化，结论简洁并引用具体数字”。报告字段、统计口径与输出校验仍由程序保留。分析进行中暂不可编辑设置；保存或切换设置不会自动联网，模型选择和二级提示词随普通配置备份。

图表末尾的“请求 AI 分析”是主动联网操作：点击后把当前范围的汇总、作者/话题/功能排行发送给本地分析所选的模型，成功后隐藏请求按钮，在报告底部直接显示完整且可复制的结果，各图表下方也保留对应解读。“分享分析文字”通过系统菜单转发完整解读；“导出/分享报告”可选单张长图 PNG 或单份 A4 分页 PDF，在本地生成全部报告区块、图表及已有分析，不再次请求 AI。没有 AI 结果也可导出，并注明尚无分析。

导出采用独立浅色纸张版式，不受屏幕深浅色或折叠状态影响；PDF 是图片型报告，不支持选择其中的文字，需要文字时使用“分享分析文字”。长图超限时提示选择 PDF，PDF 过长时可缩小统计范围，不裁掉后文。Android 10 及以上将 PNG 保存到相册 `Pictures/DouAi`、PDF 保存到 `Downloads/DouAi`；Android 9 为两种格式分别通过系统选择器保存单个文件。文件包含作者、话题、最近记录与 AI 文字，后者可能引用所填自述，请核对后再分享。打开分享面板后完成文件会保留，取消选择接收方不会自动删除。刷新、切换范围、重新分析、修改分析模型或二级提示词、关闭会取消未交接任务；修改分析设置后需重新请求分析。结果仅在当前报告会话保留，旧解读不会用于新图表或新设置。完整口径和验证边界见 [本地数据分析](local-analytics.md)。

## 基本功能：启动与弹窗

### 关闭启动干扰

在“基本功能”按需打开“去除启动和闪屏广告”“去除更新弹窗”“去除青少年弹窗”。三个开关分别控制对应的展示入口。

启动与闪屏广告设置要在下一次启动时观察。更新提示开关控制抖音应用内更新弹窗；青少年开关控制模式引导提示。

### 与推荐过滤的区别

基本功能处理启动和提示窗口。推荐视频中的广告、直播、图集等内容，要到“视频筛选”配置。关闭一种入口不会自动打开另一类过滤。

## 界面与九宫格手势

### 整理视频界面

“悬浮条”在当前视频页提供快捷操作。“隐藏拍摄+号图标”只隐藏图标，原按钮点击区域仍保留。“隐藏上下黑边”处理视频页上下留白。

“禁用双击点赞”关闭抖音的双击点赞动作。“不允许系统跳过已隐藏视频”与“不允许中途插入视频”分别限制当前信息流的删除跳过动作和播放过程中的插播动作。

### 给长按或双击分配动作

1. 打开“长按事件”或“双击事件”。两类手势独立配置。

2. 按屏幕九宫格选择左上、上中、右上、左中、中央、右中、左下、下中或右下。

3. 为该区域选择“无”“快捷菜单”“复制文案”“保存媒体”“打开评论”“隐藏/显示组件”“倍速”或“视图查找”。

4. 返回当前推荐视频，在相应区域触发手势。动作针对当前作品，离开视频页或进入不支持的页面时可能不可用。

“保存媒体”使用“下载相关”中当前选定的下载方式及保存位置；官方下载手势先弹窗选择，确认后才开始保存。选择第三方下载后，手势不会同时执行官方下载。

### 避免原生手势冲突

“拦截长按倍数启用场景”关闭抖音自带的长按倍速入口。“拦截系统长按手势”控制未设置模块快捷动作的区域是否继续交给抖音原生长按；这两个开关用途不同。

双击动作与原生双击点赞需要结合配置。需要保留抖音原本行为时，将对应区域设为“无”，并检查相关拦截开关。

### 顶部标签、沉浸与刷新

打开“隐藏顶部Tab开关”后，在“设置顶部Tab”勾选要隐藏的名称。已读取到标签列表时至少保留一个顶部标签；尚未读取到列表时可输入名称，多个名称用逗号分隔。

“沉浸式全屏”中分别选择隐藏状态栏和隐藏导航栏。“首页刷新确认”会在重复点击首页标签触发刷新时先弹出确认。

## 视频筛选：过滤推荐内容

### 按类型过滤

先打开“过滤总开关”，再选择去广告、去直播、去推荐卡片、去推荐商家、去商品/购物卡片、去热点榜单卡、去小游戏或去图集。商品/购物卡片与热点榜单卡使用独立开关；附近广告卡包含在去广告条件内。满足任意已开启条件的作品会被筛掉。过滤依据抖音当前提供的作品标记和信息。

“整页筛空时保留原列表”默认开启：如果某一页内容全部被筛掉，会保留该页原列表并跳过这次筛选。因此偶尔看到符合过滤条件的内容，可能是整页筛空保护生效。

### 设置时长和点赞阈值

“去长视频开关”会过滤明确的长视频类型，以及超过“最长时长（秒）”的作品；默认 120 秒。

“过滤短视频”会过滤低于“最短时长（秒）”的作品。例如最短时长为 10，已知时长小于 10 秒的视频会被过滤，等于 10 秒的不会因为此条件被过滤。

在“最低点赞数（0不限制）”填写实际点赞数：例如 100 会过滤已知点赞数小于 100 的作品，填 0 不限制点赞数。时长或点赞数据未知的作品不会单凭未知值触发对应阈值过滤。

### 按文字过滤

在“屏蔽关键词”填写关键词，多个词可用英文逗号、中文逗号或换行分隔，留空关闭。会检查作品可读取的文案、音乐标题、作者名等文字；包含任意一个词即可匹配，英文大小写不敏感。

示例：广告,带货。修改后观察新加载的推荐内容。该功能与自动回复、自动评论的对象范围和关键词筛选独立。

## 下载相关：方式、目录与第三方 GET

### 选择下载方式和保存位置

1. 打开“启用下载菜单”。

2. 在“下载方式”选择“官方下载”或“第三方下载”，两者互斥，只显示当前方式的设置。切换后之前填写的另一种方式配置会保留。

3. 打开“保存位置”，用系统文件夹选择器选择目录并授权，或选择“恢复默认位置”。官方下载和第三方下载共用这个位置。

4. 从作品长按下载入口、模块下载菜单，或已分配的手势“保存媒体”发起保存。选中第三方时先请求解析接口，再按已选下载字段显示媒体类型与来源字段，确认后才下载媒体；不开启官方下载回退。第三方“直接保存全部媒体”默认关闭，开启后解析成功即保存所有已配置下载字段，跳过选择。两种方式的同名开关独立保存。

5. 官方下载手势先按图片、动态视频、实况、视频或音频分类，只显示当前作品包含的类型及数量。进入图片、动态视频或实况分类后，可保存当前项、多选或全部；多个动态视频按各自原始图集序号保存。返回回到上一层，取消不下载。已标记实况但缺少动态来源时会在点击保存后提示原因。音频保存作品已有原声/配乐来源。

6. 官方下载中的“直接保存全部媒体”默认关闭；开启后手势不显示下载选择，直接保存视频或全部图片。关闭后恢复分类、多选和实况选项。两种行为使用同一命名与保存位置。

目录授权失效或目录被删除时，请重新选择。Android 9 使用默认公共目录时还需要抖音存储权限。默认的模块官方媒体保存按类型进入 Movies/DouAi、Pictures/DouAi 或 Music/DouAi；第三方作品包默认位于 Download/DouAi。抖音完全原生的保存位置以抖音自身行为为准。

### 官方下载与文件名模板

“自定义文件名”可让模块按模板保存视频、图集和音频。可用字段：#author# 作者，#desc# 文案，#aid# 作品 ID，#date# 日期，#index# 序号，#ext# 扩展名。

示例：#author#_#aid#_#index#.#ext#。

“去除下载限制”使用当前作品已有且可读取的媒体来源。“无水印下载图集或者视频”使用已识别的无水印资源；没有无水印来源时不会凭空产生无水印文件。实际可保存媒体取决于当前作品及接口适配。

### 下载菜单中的动作

选择官方下载时，下载菜单根据当前作品提供原生保存、下载音频、保存播放源视频、下载已标记无水印的视频或保存图集等可用项；有自定义目录时原生保存项改为保存当前作品到所选目录。只显示当前作品确有来源的媒体动作。

选择第三方下载时，关闭“直接保存全部媒体”会显示与官方下载一致的分类、多选弹窗。类型来自已配置下载字段解析出的图片、视频、动态视频、音频或文件，每项标出来源字段及原序号，支持单项、多选或保存整类。命名仍使用第三方命名字段，所选文件与作品信息 TXT 一起保存；返回或取消不会下载媒体。“复制作品源数据”可将当前作品模型放入剪贴板，它复制的是可读取的数据而非已经下载的媒体。

### 查看下载进度或取消

在“下载相关 → 下载任务”查看由 DouAi 保存的官方媒体和第三方作品包。页面显示排队、下载、保存和最终结果；能取得文件大小时显示进度，不能取得时显示已下载字节数。抖音完全原生的下载仍由抖音管理。

点击对应任务的“取消下载”停止排队或正在执行的保存；取消进行中任务时会先断开请求并清理本次未完成文件，再释放任务。第三方作品包失败或取消时清理本次创建的文件，不删除原有文件。关闭任务页不会停止下载，重新打开可继续查看。

官方媒体和第三方作品包共用 2 个下载工作位、16 个等待位，重复任务不会重复提交。每项任务从开始执行起最多 30 分钟，包含第三方解析和全部文件保存；单个媒体文件仍以 512 MB 为上限。页面保留本次打开抖音期间的活动任务和最近 50 条完成记录。

### 配置通用 GET 和任意参数

GET 请求填写完整 HTTP 或 HTTPS 接口地址。作品分享链接以 {url} 占位，也可以放在路径中，模块负责提取分享文字中的链接并编码替换。

示例：https://example.com/parse?id=123&link={url}

该示例的参数名是 id、link。保存 GET 地址后，“请求参数”会自动显示地址中的参数名，无需刷新按钮。可自由添加、删除或改名，参数值选择固定值或作品链接。接口不需要参数时可以全部删除；不需要 APPID 时删除对应项；要求名称为 ID、apikey、token 时按接口文档填写原名。模块不会自行补齐这些业务参数。

参数编辑器会编码参数值，不要把整个分享文案当成固定的作品链接。没有 {url} 的地址按填写内容请求，适合不需要作品链接的接口。

### 请求头填写什么

请求头是随 HTTP 请求发送的名称和值，用来让服务商识别身份、要求格式或接受来源信息。按服务商文档填写 JSON 对象，名称和值都用双引号，值必须是字符串。无特殊要求时使用 {}。

示例：{"Authorization":"Bearer 你的密钥","Accept":"application/json"}

Authorization 表示鉴权凭证；Bearer 后保留一个空格。Accept 表示希望收到的格式。某些接口使用 X-API-Key，就写 {"X-API-Key":"你的密钥"}。请求头与地址中的 apikey 参数是不同位置，按接口要求选用。

不要填写 Host、Content-Length、Connection，值中不要插入换行。填了请求头不意味着 API 一定需要它；错误的鉴权方式通常会产生 401 或 403。

### 签名方式

接口不要求签名时选择“无签名”。需要当前提供的 MD5 规则时选择对应签名方式，填写“签名密钥”和“签名请求头”，默认头名为 Sign。

当前规则是：把 GET 查询参数按参数名排序，以参数名=编码后的值用 & 连接，在末尾直接追加签名密钥，再计算小写 MD5，并放入指定请求头。与 PHP http_build_query 的值编码规则对应。签名模式不允许重复参数名。

这是特定规则，不是所有 API 通用的签名算法。服务商要求其他算法时不能仅靠改请求头名称完成适配。

### 解析响应、选择字段并命名

1. 在“响应样本”粘贴接口返回的 JSON 或 TXT，也可点“测试 GET”输入分享文字请求一次，把实际响应作为样本。测试会访问接口，可能消耗该接口额度。

2. 在“下载字段”选择包含媒体链接的字段。示例响应可选 data.video、data.video_raw、data.images、data.cover、data.audio 或 data.author.avatar；只勾选需要的文件。数组字段会保存其中的链接，同一链接会去重。

3. 在“文件命名字段”选择作者名、作品 ID 等信息，例如 data.author.nickname 和 data.id。有效字段按顺序组合，空字段会跳过，无法取得名称时使用自动名称。媒体名还会带序号及字段标识，非法文件名字符会整理。

4. 正式保存时会重新解析实际响应，媒体文件与整理后的其他信息 TXT 一起保存到作品包。未选择下载的链接仍可能作为信息写入 TXT。

TXT 可使用“标题: 内容”“视频: https://...”等字段；独立链接会归入 links。接口返回网页、空内容或所选字段没有链接时会提示失败。单次最多 64 个媒体文件，暂不支持 m3u8、mpd 播放列表。

## 自动播放与倍速

### 连续观看

打开“自动滑动到下一个视频”后，当前视频播放结束时自动切换。“滑动智能判断上下”开启时跟随最近一次手动滑动方向，关闭时使用固定下一条方向。

打开“打开评论时,不滑动视频”，展开评论列表时暂停自动切换，方便阅读和输入。该设置控制切换，不会停止视频本身播放。

### 自动与手动倍速

打开“自动倍速播放”，设置“倍速数值”，有效范围为 0.25 至 4。例如 1 为正常速度，2 为两倍速。切换作品时应用配置。

通过手势或快捷菜单中的“倍速”也可调整当前作品。长按倍速冲突到“界面相关”检查原生长按倍速拦截。部分作品或播放器入口不支持倍速，是否成功以实际播放为准。

### 打开互动自动化

“互动自动化”用于管理自动化总开关、自动点赞、自动关注和“立即停止”。自动回复、自动评论、续火花的详细内容分别在对应主页分类中设置。

## 自动化总开关、预览与记录

### 启用与立即停止

在“自动播放 → 互动自动化”打开总开关，再启用自动点赞或自动关注。自动点赞只处理当前显示且尚未点赞的作品，自动关注调用抖音原生关注流程。

打开“开启自动回复”或启用自动评论、自动续火花时，会同步打开互动总开关。总开关控制自动点赞、自动关注和续火花；自动回复及其私聊、群聊、评论回复子项由“开启自动回复”控制，自动评论按自身开关运行，关闭互动总开关不会暂停它们。需要停用时关闭对应功能，或使用“立即停止”。

“立即停止”会关闭总开关、自动点赞、自动关注、自动回复、接收评论回复、自动评论和续火花，并取消尚未提交的自动任务。已经提交给抖音的请求需要核对实际结果。

### 限制发送数量和频率

自动回复的私聊、群聊和评论回复共用每日最大回复数及同一用户间隔；自动评论另设每日最大评论数及同一作者间隔。默认均为 0，表示不限制。每日数量按设备本地自然日重置，间隔按 UID 计算；同一人的昵称变更不会建立新的额度。

对象范围、关键词条件、每日额度和间隔需要同时满足。开启功能后仍无动作时，先检查这些条件与当前登录账号。

### 发送与记录

在自动回复或自动评论的“发送与记录”中设置延迟，范围为 2 至 3600 秒。自动回复的私聊、群聊和评论回复共用延迟、悬浮提示及保存历史设置。打开“悬浮提示”后可设置 2 至 120 秒的提示超时；尚未保存该值时默认 3 秒，已经保存的值保持不变。生成完成后会显示待发送提示；点击可查看原内容和生成内容，并选择立即发送或取消，长按提示可取消。倒计时结束后会自动提交，不是必须逐条点确认。

自动回复使用独立蓝色环形悬浮提示，私聊、群聊和评论回复共用；自动评论继续使用青绿色环形提示。两者可同时显示，分别拖动并记住位置。点击可查看目标和正文，长按取消尚未提交的任务，打开详情可暂停倒计时并选择立即发送或取消。已提交或结果未知时只核对状态，不重复发送。自动评论还显示生成、发布和重试进度。

开启保存历史记录后，从回复历史或评论历史查看对象、时间、输入、输出、模型和状态，也可清空记录。评论回复合并显示在“回复历史记录”，并标注评论回复来源。保存历史与模型上下文轮数是两种不同设置。

### 理解结果状态

“发送成功”表示收到对应原生成功结果；“已提交”表示请求已进入发送流程但结果尚未确认，不能直接等同于成功。“失败”“已取消”分别表示失败或提交前取消。

网络延迟或回调丢失时，先在实际会话或作品评论中核对，避免重复操作。生成文本成功、合成语音成功和真正发布成功是不同阶段。

## 自动回复：私聊、群聊与评论回复

### 选择自动回复内容

1. 打开“开启自动回复”，确认已登录要使用的抖音账号，再按需要启用“接收私聊”“接收群聊”或“接收评论回复”。

2. 在“回复模式”选择固定内容、AI 模型、关键词规则或随机内容。

3. 打开“回复内容”：固定模式填写固定正文；AI 模式在“模型配置”选择已保存的供应商配置并填写二级提示词；关键词模式添加关键词和对应回复；随机模式添加多个候选回复。

4. AI 模式可打开“素材识别”：识别图片默认开启，识别视频默认关闭，三种接收渠道共用。这两项都需要当前模型支持图片输入，因为视频以抽帧图片参与请求。固定内容、关键词规则和随机内容模式不读取或请求媒体，切换模式会保留已选开关。

所选回复模式、模型配置、回复内容和 AI 二级提示词供私聊、群聊及评论回复共用。关键词规则按顺序匹配收到的文字，英文大小写不敏感，命中第一条后使用其回复。未命中规则或内容为空时不发送。随机模式从已配置内容中选一条。

处理新收到的受支持文字消息；AI 模式开启图片识别后可识别受支持的图片消息。关闭识图时跳过私聊或群聊的纯图片，带真实文字的图片消息可以只回复文字；开启识图但图片地址缺失或不受支持时整条跳过，不用空图请求代替识别。自己的消息、旧历史消息和不支持的消息类型不会作为普通自动回复触发。

私聊和群聊在抖音仍运行并收到新消息时即可处理，无需进入对应聊天页。更新模块后重启抖音，使新的接收方式生效。

AI 回复图片读取最多 60 秒；达到设置的回复延迟后，排队与执行各有独立的 120 秒预算，执行包含图片、AI 请求和语音准备。关闭回复、修改相关配置或切换账号会取消尚未提交的旧任务。超时不会继续发送迟到结果；已经进入预览或抖音发送流程的请求按原有确认状态处理。

### 设置私聊范围

“接收私聊”默认开启。打开“私聊范围”选择全部、白名单或黑名单。白名单只允许选中的关系或 UID，黑名单排除选中的关系或 UID；可组合“我关注的”“关注我的”“陌生人”和“指定用户”。关系或 UID 满足其中一项即可命中名单。

“消息筛选”与对象名单独立：不限、包含关键词或排除关键词。关键词用英文逗号分隔，再选择匹配发送者或消息内容；多个关键词按任意命中处理。包含模式至少需要可匹配的关键词及字段。

在“关注与粉丝名单”刷新当前账号名单，查看我关注的和关注我的实际 UID。名单加载失败、关系未知或账号切换时，不要凭显示名称推断关系已经确认。

### 设置群聊范围

“接收群聊”默认关闭，开启后再进入“群聊范围”。先选择全部群聊、群聊白名单或黑名单，再设置“全员”“指定成员”或“仅 @我”。

群聊范围按群会话标识匹配。“指定成员”可选已读取到的群成员，也可填写 UID 或昵称，优先使用 UID。“仅 @我”检查抖音消息中的真实提及标记，单纯在正文输入同名文字不一定会触发。

群聊条件独立于私聊的关注关系和消息筛选。白名单和黑名单均可手动填写群会话 ID，没有缓存群列表时也能配置；也可先在抖音打开已有群会话，再从已读取的列表选择。

### 启用语音回复

打开“语音回复”后，先根据所选回复模式生成正文，再通过“扩展功能 → 文本转语音设置”当前选择的来源合成音频。它作用于已开启的私聊、群聊和评论回复。

只提交语音，不同时发送生成文本；语音准备或发送失败时不会改发文本。私聊和群聊的自动语音回复保留模块入口的 120 秒限制；评论回复不据宿主录音界面的 30 秒设置施加模块时长硬上限，完整正文用于合成，生成音频完整交给宿主，实际是否接受取决于接口与宿主校验。先试听，再启用自动发送。

### 接收评论回复

在“自动回复”列表启用“接收评论回复”。它是“开启自动回复”下的接收子项，默认关闭；打开子项不会自动打开父开关，父开关关闭时显示“已暂停：自动回复未开启”。

评论回复直接使用本页的固定内容、AI 模型、关键词规则或随机内容模式，以及回复内容、二级提示词和语音回复设置。AI 模式结合作品文字、我的原评论、对方回复及实际附带的识别素材生成正文。私聊与群聊仍分别使用各自范围设置；评论回复只处理能够核实为别人回复我的评论的内容。

共享的“识别图片”可读取收到的图片；评论回复优先使用对方评论附图，有附图时不额外加入作品图片，无附图才读取关联作品图片或封面。“识别视频”当前只支持评论关联作品的视频画面抽帧，不包含音频，私聊和群聊的加密原生视频暂不支持。

单次最多附带 4 张素材图片，并向模型提供来源说明；这可能只是封面或少量视频画面，不代表看过完整作品。图片与视频识别均关闭时，只发送文字，不附媒体图片。

### 前台处理与打开补扫

使用抖音时收到互动消息会触发检查，并由前台定期检查补足；每次打开抖音或从后台返回时补扫。当前账号首次启用时只建立扫描起点并记住已有回复，不追发旧消息。

进入后台后暂停新生成与提交，尚未提交的任务留待回到前台继续检查；已经提交给抖音的请求仍需核对结果。扫描起点、去重和发送额度按登录账号隔离，切换账号会暂缓旧账号尚未提交的任务。

### 评论回复额度、提示与记录

评论回复与私聊、群聊共用自动回复的每日最大回复数和同一用户回复间隔，默认均为 0，表示不限制。同一评论线程最多自动回复 3 次，以防反复互答；该保护固定生效。

延迟、悬浮提示和保存历史使用“自动回复 → 发送与记录”的配置。开启保存历史后，在“回复历史记录”查看评论回复，并通过来源标识区分。清空展示记录不清空去重账本或已用额度。

“已提交”或结果未确认的请求不会自动重发。请到原作品评论区核对，避免重复回复。

## 自动评论：作品范围与素材识别

### 配置评论内容

1. 打开“开启自动评论”，确认已登录要使用的抖音账号。

2. 选择“AI 模型”或“固定内容”，再打开“评论内容”。AI 模式在“模型配置”选择已保存的供应商配置并填写评论二级提示词，固定模式填写固定正文。

3. 设置作品范围、每日最大评论数、同一作者间隔和发送延迟，再进入推荐作品观察。

任务绑定触发时的作品，滑到下一条后原任务仍可继续排队并提交给原作品，不会改成另一条；需要停止时取消任务或关闭自动评论。AI 评论按独立任务生成，不沿用模型的多轮聊天历史；空输出不发布。

### 限制作者和作品内容

“作品范围”分为作者范围和作品筛选。作者范围可选全部、白名单、黑名单，名单可结合我关注的、关注我的、陌生人以及指定作者 UID。

作品筛选可选不限、包含关键词、排除关键词，再设置英文逗号分隔的关键词及作者、文案、标题字段。作者范围与作品筛选需要同时满足。先使用明确的作者白名单与小额度检查实际行为。

### 让 AI 读取图片和视频

“素材识别”仅用于 AI 模式。“识别图片”会读取当前作品的图集图片或视频封面；没有封面时可能提取一帧。“识别视频”会下载受支持的当前视频并抽样画面。

每次请求最多携带 4 张图片或视频帧，视频来源最大 64 MB。抽样画面不包含视频音频，模型不能据此听懂台词；使用支持图片输入的模型。

评论历史详情会显示图片请求是否已确认发送及实际携带张数。看到封面或生成结果不等于完整视频已传给模型。

### 队列、重试和结果核对

自动评论任务排队处理。启用悬浮提示后，环形提示可查看任务和剩余重试情况，并取消尚未提交的任务。文本最多尝试 3 次；开启语音时先尝试语音 3 次，均明确失败后用同一份正文转文本，文本发布仍最多尝试 3 次。正在上传或结果未确认的已提交请求不会触发重试或转文本。

生成、语音合成或发布过程中修改关键配置、关闭功能、切换账号会使尚未提交的任务失效。历史显示“已提交”时先核对作品评论。

### 启用语音评论

打开“语音评论”后优先合成并发送语音。语音合成或发布连续 3 次明确失败后，用同一份固定或 AI 正文转发文本，不重新生成评论。语音成功后不会附加文本；上传结果未确认时不会转文本。关闭开关时只发送文本。历史列表和详情显示实际发送方式“语音”或“文本”；旧记录没有这一字段时显示“未记录”。

模块不再额外限制语音评论正文的字数与合成音频时长；AI 客户端仍保留原来的 4000 字输出限制，实际仍需满足合成服务和抖音发布要求。手动输入 # 的评论转语音与自动语音评论开关独立。

## 评论相关：后缀、长按与语音

### 后缀和彩色评论

打开“评论自动添加后缀”，并填写“后缀内容”，本人提交的文字评论末尾会追加所设内容。留空后缀没有可追加内容。

“彩色评论”使用抖音原生文字附加参数，可选类型 0 或类型 33。显示效果取决于抖音客户端和实际发布结果，开关不会把所有人的评论统一改色。

### 长按评论工具

点击“长按操作”，在弹出的多选菜单中勾选复制评论、保存评论图片、复制源数据；设置行会显示已选操作，全部取消即关闭这些工具。长按具体评论打开抖音菜单，再长按其中的菜单项进入“评论工具”。开启“复制源数据”后，可选“查看评论数据”查看语音摘要与完整 JSON，也可直接复制。查看不会自动复制或写入日志。

复制评论将可读取正文放入剪贴板；保存评论图片处理该评论可读取的图片来源；源数据是当前评论模型的结构化内容，便于核对字段。没有对应正文或图片的评论不会凭空产生内容。

### 替换本人录制的评论语音

在“评论相关 → 评论语音文件”选择本地音频文件或填写可访问的路径，点“保存”后才应用，取消不会覆盖已有文件设置。打开“替换语音文件”，然后按抖音原本的评论录音流程录制并提交。模块使用已保存的文件替换本人这次录音，文件本身要能被抖音进程读取。

此录音替换功能要求音频不超过 20 MB、时长不超过 30 秒。重新选择文件后，先等待准备完成；该开关不会替换其他人的已发布语音。

### 手动评论文字转语音

打开“评论自动文本转语音”，在纯文字评论前输入 #，例如“#你好，今天的视频很有趣”，点击抖音发送按钮后合成并走原生语音评论发布。实际合成内容不包含开头的 #。

合成来源在“扩展功能 → 文本转语音设置”选择，也可从“评论相关”的“文本转语音设置”快捷入口打开。模块不再额外限制合成评论的字数与音频时长，实际仍需满足合成服务和抖音发布要求。没有 # 的评论仍按文字处理；已包含图片、视频等附件的评论不按纯文字转换。生成失败会提示，不自动改发同一段文字。

## 自动续火花：每日发送与时间窗口

### 设置续火花对象与内容

打开“自动续火花”，在“选择用户”选择已有单聊对象，填写“续火花内容”。只处理所选的单聊，不用于群聊。开启功能时会同步打开自动化总开关。

模块每 30 秒检查一次，在条件满足时每个所选对象每日发送一次。运行检查需要抖音进程存活及当前账号可用，不是系统闹钟，也不保证在应用退出或设备休眠时准点执行。

### 限定发送时间

在“续火花限制时间”填写 HH:mm 格式，例如 09:00 至 22:00。支持跨午夜窗口，例如 23:00 至 01:00。开始和结束都留空表示全天；二者相同也表示全天。时间格式无效时不会发送。

每日记录按当前账号、对象和设备本地日期区分，跨午夜进入新的一天可能有新的发送机会。设置时间窗口后请检查设备时间与时区。

### 从接口读取续火花文字

“内容Api”可填返回纯文字的 HTTPS 地址，返回的文字优先于固定内容；留空则使用“续火花内容”。接口应直接返回要发送的正文，不要返回带外层对象的 JSON 或网页。

请求失败、超时或内容为空时本次不发送，不会无条件改用固定内容。该接口配置与第三方下载、第三方语音 GET 各自独立。

### 成功、未知与手动重试

“续火花成功弹出Tip”控制结果提醒。成功发送会记录当天结果；已提交却未收到明确回调的记录会保留为结果未知，以免自动重复发送。

使用“重试结果未知的续火花”前先到目标会话查看，重新发送可能造成重复消息。“清空续火花记录”会重置本地判断，可能使当天已有对象再次发送，不会删除抖音会话中的消息。

## 组件隐藏、透明度与自定义视图

### 按组件调整显示

进入“组件隐藏”打开“隐藏总开关”。可分别调整头像、点赞、评论、收藏、分享、音乐碟片、卡片、作者昵称、共创、视频描述、音乐信息、全屏、顶部导航、底部导航、轻反馈、进度条、底部工具、时间属地。“卡片”指作者昵称头顶的卡片。

透明度范围为 0 至 255：255 完全显示，0 完全透明；透明控件仍可能保留布局与点击区域。-1 表示隐藏但保留占位，-2 表示移除布局占位。“统一透明度开关”开启时使用统一数值覆盖各组件的独立数值，关闭后可继续使用之前的分项配置。调整任意单项透明度会自动关闭统一模式，改为按分项数值应用。

### 切换、暂停和手势显示

“切换视频时,自动执行隐藏View”会在换作品时应用隐藏。“暂停播放时,显示View”会在暂停时恢复组件显示。“显示View时,自动打开评论列表”可在显示组件时打开评论。

可在“界面相关”给长按或双击分配“隐藏/显示组件”，临时切换当前作品组件状态。找不到按钮时，先关闭隐藏总开关或把透明度恢复 255。

### 添加自定义视图

1. 在“界面相关”将某个手势区域设为“视图查找”，返回目标视频页触发。

2. 点选控件后，蓝框表示当前选中目标。重复点击同一位置或点击“重叠”切换该位置的候选，面板显示当前候选序号。默认只显示选中轮廓；需要观察全部控件时，点击工具条的“轮廓”。工具条与选择面板都可以拖动，横屏时分列显示。

3. 点击“展开”使用上一个、下一个、父节点、子节点和滑条导航；“收起”减少遮挡。“View树”支持按类名、完整资源 ID、文字或内容描述搜索，多关键词同时匹配，也可筛选仅可见或可交互的视图。结果保留原编号，页面变化后可刷新，误选可撤销。

4. 点击“属性”查看并复制完整类名、尺寸、坐标、状态、内外边距和定位路径。打开“规则”确认作用域与定位方式后保存，或直接点击“隐藏”。如果视图已移除或结构改变，需刷新后重新选择。

5. 回到“组件隐藏”的“自定义视图”查看数量和规则作用域，点击条目查看、复制规则信息，或删除规则恢复该视图。

自定义规则依赖页面结构，抖音版本或页面结构改变后可能无法匹配。规则不保存页面文字或屏幕坐标；密码内容不会进入搜索和属性复制。原生 View 树不能直接展开 Canvas 内部绘制、WebView DOM 或每个 Compose 节点；扫描达到上限时会提示结果可能不完整。避免隐藏过大的父容器；无法操作时关闭总开关、删除该规则，再重新定位。

## 消息管理：防撤回与手动语音

全局长按入口在“评论相关”主页面：开启“#长按发送转语音（全局）”，在私信、群聊、评论或评论回复输入 `#内容` 并长按原生发送按钮，仅发送合成语音。失败保留草稿，不回退文字；不带 `#` 的长按保持原生行为。该开关默认关闭，与下面既有单击转语音开关独立。

### 保留本地消息

开启“消息防撤回”，再选择是否保留自己撤回和对方撤回的消息。“撤回的背景色”用于区分本地保留下来的内容。

防撤回依赖已经在本地收到的内容，不能恢复从未接收过的消息，也不会撤销服务端撤回状态。已撤回内容是否还能显示取决于当前消息类型和适配。

### 替换本人私聊录音

在“消息相关 → 私聊语音文件”选择音频文件或填写可读取路径，点“保存”后才应用，取消不会覆盖已有文件设置。打开“替换私聊语音”，按抖音原本的录音流程完成录音时，模块会将已保存的音频用于替换本人录音。

先等待文件准备完成，使用设备可以解码的音频。该功能控制本人的录音提交，不会修改对方发来的语音，实际发送仍走抖音原生流程。

### 用 # 发送合成语音

开启消息的“自动文本转语音”，在单聊输入框中输入“#你好”并点击抖音原生发送按钮。模块去掉开头 #，使用共享的语音来源合成，再准备音频并提交。可从“消息管理”的“文本转语音设置”快捷入口调整共享的合成来源和参数。

不带 # 时照常发送文字。失败时提示并保留草稿，不会把待合成正文自动当作普通文字发出。生成过程中避免切换会话或反复点击发送。

这一手动开关与“自动回复 → 语音回复”独立；自动回复语音不要求收到的消息或生成正文带 #。

## 本地伪装：主页数量与版本显示

### 调整本人主页显示

开启“伪装总开关”，为获赞、关注、粉丝、互关数量填写显示值。字段留空使用原始数量。只影响本人主页的本地显示，真实关注关系、服务端统计和其他用户看到的数量不会因此改变。

需要核对真实数据时关闭总开关，重新打开本人主页。

### 修改进程读到的版本信息

进入“版本信息”，开启“版本信息修改”，填写版本名称和数字版本号。修改的是抖音进程读到的版本信息，不会替换安装包，也不能让未适配版本自动获得兼容性。

排查兼容问题时关闭版本修改，核对实际安装版本后重启抖音。

## 扩展功能：AI 模型与消息对话

### 添加并保存模型

进入“扩展功能 → AI 模型设置”，选择“添加模型配置”和供应商预设，再核对配置名称、接口协议、API 基础地址、密钥与模型名称。模型管理只负责添加、编辑、保存或删除配置，编辑器统一点击“保存”；首次添加也不自动选择全局默认或任何功能模型。

需要选择全局默认时，在快捷菜单打开“切换模型 → 全局默认”，再选已保存的配置。“测试当前配置”和音色列表“翻译名称”等使用全局默认的入口，需要先完成这一选择。模型编辑器的“测试对话”使用当前草稿，不会修改全局默认或各功能的选择。

支持 OpenAI Chat Completions、OpenAI Responses、Claude Messages 和 Gemini 协议。选择协议需要与服务商实际接口一致，不能仅凭模型名称判断。

例如 OpenAI 兼容服务可填写 https://example.com/v1，模块按协议拼接操作路径。密钥栏填写密钥本身；特殊鉴权再按服务商要求设置请求头。“获取模型列表”失败时可以手动填写准确模型名，列表接口不可用不代表对话接口也不可用。

### 分别选择各功能模型

自动回复（私聊、群聊、评论回复）在“自动回复 → 回复内容 → 模型配置”选择，自动评论在“自动评论 → 评论内容 → 模型配置”选择，本地数据分析在其 AI 分析区域选择。快捷菜单“切换模型”也可先选择功能，再选择配置。后三项默认“跟随全局模型”，也可各自选择已保存配置，彼此可相同或不同；每次只修改所选功能，不改变全局默认或其他功能的选择。

例如已添加供应商 A、B、C，可让自动回复使用 A、自动评论使用 B；评论区回复与私聊、群聊共用自动回复所选配置。

各功能使用所选配置的接口、密钥、模型、一级提示词、响应方式（流式或非流式）、推理强度及其他请求参数。显式选择已保存配置时不要求已选择全局默认；选择“跟随全局模型”时需要先选择全局默认配置。所选配置被删除后需重新选择，不会自动切换到其他供应商。

### 加入抖音消息界面

编辑已保存的模型，点击“模型配置”标题下方居中的头像，可选择图片或恢复默认。填写联系人名字，在页面底部打开“加入抖音消息界面”并保存，然后进入抖音“消息”页，点击模型联系人开始对话。可同时加入多个模型，联系人开关不改变全局模型或自动回复、自动评论各自的选择。名字留空时使用配置名称，头像保存在配置内。

对话页右上角“更多”菜单提供“修改联系人”和“清空聊天记录”。修改后再次点击消息页联系人即可使用新设置。每个模型的消息对话与测试对话分开保存，携带最近的上下文轮数，设为 0 时不保存历史；改名字、头像不清空记录。关闭联系人开关会移除入口，重新开启仍可读取保留的记录。

对话中的附件按钮可选择图片、视频和文件。消息页聊天的图片和视频使用抖音原生选择器，文件使用系统文档选择器。选择后先以一张附件卡片暂存，可继续填写问题或说明；点击发送后才读取附件并请求模型。删除卡片会移除该附件的整组内容，识别范围见下方说明。模型联系人由模块在本机提供，对话通过该模型已配置的接口请求。

消息联系人的聊天页按实际版本复用抖音 40.6.0 / 40.8.0 的原生聊天布局、标题、输入栏与文本气泡，以全屏页面显示。发送按钮由 DouAi 处理，聊天记录仍保存在模块的本地历史中。其他抖音版本或控件不匹配时会提示尚未适配。模型设置中的“测试对话”继续使用原有界面。

消息行显示双方圆形头像；自己的头像通过抖音当前账号的头像加载器读取，AI 头像使用该模型配置。底部加号用于选择附件，表情和快捷卡片将内容填入草稿，语音入口调用设备上的系统语音识别服务填入文字；没有可用服务时会提示。工具按钮可打开附件或联系人操作。文字或附件准备好后显示原生发送按钮，请求期间可停止。

### 一级与二级提示词

模型配置中的“一级提示词”设置通用身份、语气与约束。自动回复、自动评论和本地数据分析各有独立的“二级提示词”，描述具体任务，与所选模型的一级内容一起参与请求。

示例一级提示词：使用简体中文，表达自然，避免编造。

示例回复二级提示词：用一两句话回复对方，只输出回复正文。

示例评论二级提示词：根据作品内容写一句相关的简短评论，只输出评论正文。

“上下文轮数”为 0 至 50，0 不携带之前的对话轮次；自动评论始终按独立作品任务生成。模型上下文与保存的发送历史分开管理。

### 高级请求设置

超时范围为 5 至 120 秒。温度、最大输出 Token、Top P 只有打开对应开关才可编辑并作为可选参数发送。关闭后保留原先保存的数值，不会因为未启用字段的空草稿而阻止保存；数值范围以保存时校验提示为准。自定义参数填写 JSON 对象，不能覆盖 model、messages、input、stream 等协议基础字段。

自定义请求头使用字符串值的 JSON 对象，例如 {"X-API-Key":"你的密钥"}。API 基础地址不能带查询参数、账号密码或片段。HTTPS 默认可用；服务只提供 HTTP 时需要在该模型配置中明确启用“允许不安全 HTTP”。

手机访问本地部署服务时，localhost 或 127.0.0.1 指向手机自身；电脑上的服务应填写手机能访问的电脑地址。

### 测试文字、图片、视频和文件

先在“测试当前配置”或模型编辑页的“测试对话”发送短文字，确认鉴权、协议和模型名可用，再测试附件。“测试当前配置”使用已选择的全局默认，编辑页“测试对话”使用当前草稿。附件菜单可选择图片、视频或文件；选择后先暂存为附件卡片，可填写文字后一起发送。点击发送才开始读取内容或抽取画面，选完附件不会自动请求模型。每次请求最多携带 4 张图片或视频帧，以及最多 4 个文件或视频说明。

消息对话与测试对话共用附件读取能力。视频只提供抽样画面，不包含音频或语音，最大 64 MB；发送时附带时长和抽样位置说明，少量画面不代表完整视频。文件支持 UTF-8 文本（如 TXT、Markdown、CSV、JSON、代码）、DOCX 和 PDF；DOCX 读取正文，PDF 按剩余图片名额渲染前几页，最多 4 页。文本文件最大 1 MB，DOCX/PDF 最大 16 MB，读取文字最多 16000 个字符。无法读取的格式会提示。视觉内容需要模型和服务接口支持图片输入。

读取附件需要时间，视频耗时取决于文件与设备解码器。读取或请求中可点停止，失败时可保留草稿或重试，清空对话可清除测试聊天记录。测试对话用于检查模型，不会把测试内容发送给抖音好友或发布为评论。

## 扩展功能：文本转语音

### 选择来源并试听

进入“扩展功能 → 文本转语音设置”，在“语音来源”选择系统引擎、第三方、MiniMax、Breeze Blue 或 Fish Audio。只显示当前来源的设置，各来源的已保存配置会保留。

这项来源选择供手动 # 转语音、自动回复语音和自动评论语音共用。选择第三方、MiniMax、Breeze Blue 或 Fish Audio 后，合成走所选接口；失败不会自动换用其他语音来源。第三方主界面保留“合成 GET”“合成参数”“接口设置”“音色”“音色高级设置”和“试听”。合成请求头、响应样本和音频地址字段归入“接口设置”；列表 GET、刷新音色及列表解析归入“音色高级设置”。配置后先点“试听”输入短文字确认音色与输出。

### 配置 MiniMax

选择 MiniMax 后进入“接口设置”填写 API Key 和 API 地址，地址默认 https://api.minimax.cn。主页面选择模型和音色，模型默认 speech-2.8-hd；需使用支持语音合成的模型。密钥与 AI 文本模型设置分别保存。

点“音色”先看缓存列表，再点列表内的“刷新”读取账户可用的系统、克隆和文生音色；也可点“手动填写”输入 voice_id。打开列表不会自动联网或合成。默认音色 male-qn-qingse，名称只用于显示。更换账户或 API 地址后重新刷新列表；自定义音色需当前账户拥有权限。

MiniMax 的语速范围 0.5 至 2、音量大于 0 且不超过 10、音调为 -12 至 12 的整数，默认分别为 1、1、0；与系统引擎和第三方设置分别保存。合成通过官方同步接口生成音频，默认 MP3，也可在“音频输出”选择 WAV、FLAC、Ogg/Opus、μ-law WAV 或实验 AAC；正文须少于 10000 个字符，仍受 60 秒合成超时和 20 MiB 音频上限约束。

设置后先用短句试听。提示 1004/2049 时检查密钥，1008 检查余额，1002/1039 表示请求过于频繁，2013/20132 检查模型与音色参数，2042 检查音色权限。试听成功后，所有共享 TTS 入口使用同一 MiniMax 配置。

### MiniMax 模型列表

点击“模型”先看缓存或内置语音模型列表，也可“手动填写”。选择框标明内置官方列表、接口列表或官方文档列表；当前模型未在列表中时单独标注。打开列表不会自动联网。主页面不再分散显示刷新行。

点模型列表底部的“刷新”，再选“当前接口模型（使用 API Key）”或“MiniMax 官方目录（无需 Key）”。前者按当前 API 地址和 Key 请求模型接口，只保留 speech- 开头的语音模型；接口只返回文本模型、为空或失败时保留原列表，不会自动选择其他模型。

官方目录读取 MiniMax 同步语音接口的公开支持清单，不代表账号权限或额度已经验证。只有点选具体刷新来源才发出目录请求，不会触发语音合成。切换 API 地址或 Key 会取消旧请求，清除来自旧接口的模型缓存；关闭设置页也会取消请求。

### MiniMax 高级设置

主页面“朗读设置”合并语速、音量和音调。“MiniMax 高级设置”分为“音频输出”“语言与发音”“混音与声音效果”，分别管理输出参数、语言读法及音色效果，已有值继续保留。音频输出可选 MP3、WAV、FLAC、Ogg/Opus、μ-law WAV 和 AAC（实验）。AAC 直接请求接口，官方文档未列支持，接口可能拒绝；默认仍为 MP3。μ-law WAV 固定 8 kHz，原始文件不改写；Opus 使用 .ogg 容器。只有 MP3 发送码率参数。

“返回方式（传输）”可选 URL 或 Hex，默认 URL；它只决定接口返回音频链接还是十六进制数据。Hex 仍受 2 MiB 文本响应上限约束，较长或无损音频建议使用 URL，下载音频上限为 20 MiB。“混合音色”每行填写 voice_id/权重，例如 voice-a/30、voice-b/70，最多 4 行、每个权重为 1 至 100 的整数。启用混音后原单音色暂不参与，清空混合音色即可恢复；可试听确认效果。

情绪默认自动；当前模块仅在 speech-2.6-hd/turbo 开放流利与低语。高质量文本归一化仅在 2.8/2.6 系列开放。旧 01/02 模型不支持波斯语、菲律宾语和泰米尔语增强；不兼容组合会在保存时提示。

声音效果器的音高、音强和音色调整范围均为 -100 至 100，与“朗读设置”中 -12 至 12 的音调分别保存。可单选空旷回声、礼堂回声、电话音质或机器人效果。效果器只支持 MP3/WAV/FLAC，切换其他格式前先重置音色调整；格式与效果不兼容时会提示。

发音字典每行填写“原文/替换内容”，例如 处理/(chu3)(li3)。模块限制最多 128 条、每条 1024 字符、合计 64 KiB。LaTeX 朗读仅使用中文，需将语言增强设为中文或不指定，公式用 $$ 包围。AIGC 水印可选择默认、开启或关闭。这些参数供试听与所有正式合成入口共用。

### 配置 Breeze Blue

选择 Breeze Blue，在“接口设置”填写独立的 API Key，地址默认 https://api.breeze.blue。Key 只填密钥本身，不借用 MiniMax、Fish 或文本 AI 的密钥。主页面的“语音模型”“音色”“朗读设置”“高级设置”和“试听”分别管理该来源参数。

新配置的“语音模型”默认“自动按语言选择”，表示省略 model_id：显式语言 en/zh 由服务选择 breeze-tts-2，其它或省略语言选择 breeze-tts-2-multilingual。服务不据正文猜模型；已保存的显式模型不自动替换。breeze-tts-2 仅支持显式 en/zh，其它语言需选择兼容模型。

音色必须明确选取 voice_id，没有虚构的默认音色。可以刷新账户音色首屏或手填 ID；名称只用于显示。音色库支持全部/系统/个人范围、名称搜索和目录语言，依据 Breeze 的 voice_type、search 和查询字段 language_code；不套用 Fish 的 self/public。目录语言独立于合成语言，修改筛选仅清该来源音色缓存，已选 ID 保留。

刷新先显示首屏，后续通过“加载更多”按 Breeze 的 has_more、游标或页码追加，不先等待全库。标题标明已加载数量和继续状态；后页失败、分页不前进或达到本机预算时，保留已加载项与当前选择，可缩小搜索。打开选择框只看缓存，缓存可能是部分浏览结果，不标为完整账户目录。模型目录和音色每页有 45 秒模块等待预算；关闭或切换条件取消旧请求并拒绝过期回写。Breeze 目录需有效 Key，匿名 HTTP 可达不能代替账户目录验收。

### Breeze Blue 语音指令

在“语言与表达”填写与正文相同语言的朗读指令，再点击“优化指令”可明确请求 Breeze 优化当前草稿。优化接口只收到指令和可选语言，不收到待合成正文，也不翻译指令；结果先成为可检查、可继续编辑的草稿，保存后才生效。打开或保存设置不会自动优化。

优化接口要求非空、最多 1000 字符的指令，这是优化操作的限制，不是给普通合成 instructions 杜撰上限。关闭编辑器、修改草稿或切换来源会停止本次优化并拒绝迟到结果。

语速 0.5 至 2、音量 0.01 至 2，默认均为 1；音量是线性倍率。指导强度 1 至 10、默认 1，说话人增强默认关闭。有非空指令且指导强度大于 1 时增强不生效；其它情况下增强开启使有效指导强度为 1，指令仍生效。当前无效控件隐藏并提示原因，原保存值保留。

### Breeze Blue 高级设置

“音频输出”支持 MP3、WAV、FLAC、AAC 或 Opus；可按格式选择采样率、码率，或手填 mp3_44100_128、wav_48000 等。码率单位 kbps，显式码率需先指定采样率；WAV/FLAC 不带码率。默认 mp3 为原生 24000 Hz，固定单声道，提高输出采样率不增加源带宽。

“生成返回方式”支持同步完整音频、HTTP 流式接收、后台生成。HTTP 流式仅支持 MP3/WAV，仍等待完整文件后才试听或发送，不边生成边发布评论。后台生成只 POST 创建一次任务，再查询同一服务的任务状态，完成后从该服务的任务 /audio 地址下载；不跟随 download_url，也不因轮询重复生成。

语音指令、语言代码、指导强度与增强按 Breeze 自己的 API 提供，语言留空表示不发送该字段，不继承参考音色语言。没有 MiniMax 的音调、混音、声音效果、水印或 URL/Hex 设置。裸 PCM 无容器，当前发送入口不提供，请选 WAV；字词时间戳、实时会话控制及 ASR 不放入纯音频发送设置。

### Breeze Blue 接口与备份边界

默认账户正文上限 1000 字符，获批账户最高 2000。模块保留完整正文，不截断或自行拆请求；服务可能按自己的规则分段合并，仍不保证每个字均已朗读。既有合成截止与 20 MiB 音频预算继续适用。后台任务取消或超时不证明服务停止生成或未计费。

接口、模型、音色、音色筛选、生成返回方式和参数独立参与备份，默认去除 Key；旧密钥仅按相同服务边界恢复，目录缓存不导出。新增 HTTP 层不自动重复生成，原评论语音重试和文字回退、自动回复失败处理保持。

本说明不宣称真实账户合成、手机解码、音频质量或抖音发布已验收；具体测试和最终包证据见版本记录。依据 Breeze 官方 TTS 指南：https://docs.breezeblue.ai/guides/text-to-speech；原生 API：https://api.breeze.blue/openapi.json。

### 配置 Fish Audio

选择 Fish Audio，公开音色可先浏览；合成、试听或读取“我的音色”时，在“接口设置”填写独立 Key，地址默认 https://api.fish.audio。Key 只填密钥本身。“语音引擎”对应 model 请求头，固定候选为 s2.1-pro（默认）、s2.1-pro-free、s2-pro、s1、drama-3，不提供无效的通用模型刷新和引擎手填。候选不证明账户权限或额度。

音色与引擎分开。进入“音色 → 音色来源”选择单音色、多说话人音色或参考音频。单音色可以从库中选择或手填 reference_id，留空使用服务默认音色；改变模式保留各自配置，不改写正文或提示词。

在“音色 → 音色库”设置“音色范围”和“音色搜索”，点“刷新音色”读取首屏，随后可“加载更多”按页追加。未保存过范围时默认公开，已保存范围保留。公开目录可不填 Key 浏览；填写了 Key 时请求沿用它。“我的音色”属于当前 active workspace，需要有效 Key；真正合成和试听仍需 Key。

列表只显示 type=tts 且 state=trained 的结果，但按原始条目推进分页。公开库的“搜索窗口内结果”、非精确总数及窗口到底是正常状态，不应当作接口失败或称为完整全库。后续页失败、重复、更多状态未知或达到本机 200 项浏览预算时，保留已加载音色和当前选择，可缩小搜索后刷新。详见 [窗口行为与修复记录](2026-10-27_fish-catalog-window-fix.md)。

### Fish Audio 多说话人与参考音频

多说话人模式中按顺序添加音色，同一 ID 可以用于不同说话人。正文须自行写 <|speaker:0|>你好。<|speaker:1|>你好呀。 等标签，编号与列表顺序对应且从 0 开始。S1 不支持多说话人。编号越界、标签错误或缺少所需标签会提示，模块不自动插标签或改写台词。

参考音频模式中点击“添加参考音频 → 选择音频文件”，支持 WAV/MP3/FLAC；填写说话人编号与音频实际说出的精确“样本原文”，保存样本后“保存并使用”。同一说话人可有多份样本，编号从 0 连续排列；多分组正文使用相应标签，S1 只允许一个分组。

官方建议 10–30 秒清晰语音，这是质量建议而非模块时长硬上限。最多 8 个说话人/分组、每组 4 份样本、参考音频合计 8 MiB 是模块编辑和素材预算，不是 Fish API 宣称的最大值。

素材先复制到当前宿主的本机目录，合成时将原始字节和逐字原文作为 references 以 MessagePack binary 发送给 Fish，不把音频作为 Base64 配置备份，不创建或训练远端声音模型。取消未保存编辑会清理此次未使用的导入副本。

### Fish Audio 朗读与高级设置

语速 0.5 至 2、默认 1；音量 -20 至 20 dB、默认 0，是分贝增益而非其它厂商倍率。响度归一化默认开启，S1 不生效时控件隐藏且请求不发该字段，保存值保留。

音频输出支持 MP3/WAV/Ogg-Opus。MP3 采样率 32000/44100 Hz，码率 64/128/192 kbps；WAV 为 8000/16000/24000/32000/44100 Hz，不发送码率；Opus 为 48000 Hz，码率自动或 24/32/48/64 kbps，实际发送 bps。采样率可用接口默认，固定单声道；完整音频后才使用。裸 PCM 无容器，当前入口不提供，请选 WAV。

原生生成参数保留：温度与 Top P 默认 0.7，延迟 normal、分段长度 300、最短长度 50、每块最大音频 Token 1024、重复惩罚 1.2、关联前序开启、提前结束阈值 1、质量保护关闭。采用原生 OpenAPI 的 normal/300 默认，不套用另一指南的 balanced/200；这些分块是服务端行为，不是模块截断正文。

文本归一化默认开启；开启时可留空/auto 或填写 zh-CN 等语言标签，只影响数字日期等读法，不切换音色或口音。关闭后隐藏语言并在纯音频请求省略该字段，保存值保留。本功能不请求时间戳。S2 的表达标签为方括号，S1 用其固定圆括号标签，Drama 3 有自己的自然语言和成对标签；均由你写在正文中，不自动转换。

### Fish Audio 发音字典

“语言与发音 → 发音字典（JSON）”接收最多 3 个同类字典：全部为已发布 id/version 引用，或全部为内联 items，不能混合。引用须使用准确版本，不能用 latest；找不到的字典可能被服务跳过，合成成功不证明字典已经生效。

内联示例：[{"items":[{"key":"Kubernetes","value":"K UW2 B ER0 N EH1 T IY0 Z","case_sensitive":false}]}]。每字典最多 5000 项，key 为 1–256 字符、value 为 1–1024 字符。value 是发音符号，英语使用 CMU Arpabet、中文用声调数字拼音，不是任意替换正文或自动 IPA 转换；不要自行加 phoneme_start/phoneme_end 标记。

### Fish Audio 接口与备份边界

一般参数和说话人 ID 数组可以备份，默认去除 Key；本机参考音频、路径和样本原文不导出，也不能从备份注入。已有合法本机素材绑定保留，跨设备恢复后需重新导入。旧密钥只按同一服务边界恢复，不借用其它来源 Key；目录缓存不导出。

模块保留完整正文与生成音频，不套用 Breeze 字符上限，不自行拆段、转码或重封装。仍受所选引擎、账户、既有合成截止、20 MiB 音频预算及发送入口约束。新增 HTTP 层不自动重发生成；原评论语音重试和文字回退、自动回复失败策略不变。

此处只做 /v1/tts 文转音，不包含 ASR、模型训练/发布管理或字词时间戳。不宣称真实账户合成、音频质量、手机解码或抖音发布已验收；版本记录单独给出本地测试证据。依据 Fish 官方 TTS 指南：https://docs.fish.audio/features/text-to-speech；原生 API：https://api.fish.audio/openapi.json。

详细步骤、完整范围与对应官方来源见 [Breeze Blue 配置说明](breeze-speech.md) 和 [Fish Audio 配置说明](fish-speech.md)。

### 生成格式与原文件发送

评论直接使用来源生成的文件，不做本地转码或重新封装。MiniMax 的 AAC 是实验性 API 选项，服务端拒绝时会报告错误，不悄悄切换成 MP3。第三方、Breeze Blue 和 Fish Audio 返回的音频也按实际文件处理。

后缀按文件内容识别：ADTS AAC 为 .aac、MPEG-4 音频为 .m4a、Ogg/Opus 为 .ogg、WAV 为 .wav。改后缀不会改变编码；返回什么有效音频就用什么文件。评论入口不新增 30 秒截断，私聊/群聊保留既有宿主发送处理。

### 系统引擎设置

在“接口设置”中，“语音引擎”填写设备上已安装的文字转语音引擎包名，留空使用系统默认引擎。“语音语言”使用语言标签，例如 zh-CN。设备需要安装并支持所选语言的数据。

“朗读设置”中的“语速”和“音调”默认 1，可保存范围为 0.5 至 2；越界或无效输入会提示且不保存。旧配置显示实际有效值，与试听及正式合成一致，打开页面不会改写原配置。系统引擎可能需要先在 Android 的文字转语音设置中完成初始化或下载语音数据；文本长度仍需满足该系统引擎的要求。切换第三方后这些系统数值不用于第三方请求。

### 配置合成 GET 和参数

“合成 GET”填写 HTTP 或 HTTPS 地址，使用 {text} 表示待合成正文，{voice} 表示选中的音色编号。可以把占位符放在参数值或路径，运行时会编码替换。

当前示例：http://www.yx520.ltd/API/wzzyypromax/api.php?voice={voice}&apikey=你的密钥&text={text}

在“合成参数”可以增删参数、修改参数名，并选择固定值、待合成文本或已选音色。不同 API 可以使用 id、speaker、token 等名称，不需要 apikey 或音色参数时删掉相应项。保存 GET 后参数显示自动更新。

“合成请求头”按服务商文档填写字符串值的 JSON 对象；不需要时为 {}。这与下载 GET 相同的参数编辑方式分别保存，下载签名设置不会自动用于语音 API。

### 响应样本与音色高级设置

“接口设置”中的“合成响应样本”和“音频地址字段”参照第三方下载的响应解析方式，用来预览并选择 JSON/TXT 中的音频链接。已有配置继续保存并生效。

“音色高级设置”集中管理列表 GET、刷新音色、列表请求头、列表/编号/名称字段和样本。主合成请求头、响应样本与音频地址字段位于“接口设置”，与列表设置独立保存。

接口可以直接返回可解码的音频，也可返回 JSON 或 TXT 中的音频地址。

示例响应：{"code":"200","url":"https://example.com/voice.mp3"}，字段填写 url；如果链接在 data.audio_url，填写 data.audio_url。留空时尝试识别常见音频字段，多个候选地址或无法识别时应填写明确路径。

地址指向的文件需要是真实音频，网页、错误提示或不能解码的文件不能作为语音。响应文本上限 2 MiB，音频上限 20 MiB。

### 独立请求音色列表

“音色列表 GET”与合成地址独立，直接填写完整请求地址；接口需要查询参数时将参数写入该地址，模块不会自动添加参数，也没有单独的音色列表参数编辑入口。请求头在“音色高级设置 → 音色列表请求头”配置。点“刷新音色”请求并解析列表，然后选取音色；被选中的编号填入主 API 的 {voice}，名称只用于显示。

当前示例：https://www.yx520.ltd/API/wzzyypromax/ys.php。其 TXT 行如“1. 叶修”，音色编号为 1，显示名称为叶修，列表数量按实际返回读取。TXT 格式时，“音色高级设置”中的列表、编号、名称这三个 JSON 字段路径都留空。

JSON 示例：{"data":{"voices":[{"id":"1","name":"叶修"}]}}。在“音色高级设置”中，列表字段填 data.voices，音色编号字段填 id，音色名称字段填 name；编号与名称路径相对于每个列表项。常见格式也可留空自动识别。

可在“音色高级设置 → 音色列表样本”粘贴响应，离线检查解析；没有列表接口时在“音色”手动填写编号。接口或字段改变后重新刷新并选择；关闭设置页会取消还在进行的列表请求和试听。

### 发送时长与故障处理

作品自动语音评论、评论回复语音和手动 # 评论转语音不据宿主录音界面的 30 秒设置施加模块时长硬上限，不截断正文或音频。网络合成不套用系统引擎的文本长度限制，系统来源仍受系统引擎要求约束，第三方、MiniMax、Breeze Blue 和 Fish Audio 来源仍受各自接口要求约束；完整正文用于合成，生成音频完整交给宿主，发布结果取决于抖音的实际校验。私聊和群聊的自动语音回复保留模块入口的 120 秒限制；录音文件替换的评论语音仍保留该模块入口的 30 秒限制，它不是已证实的宿主上传上限。

共享合成不再设置 120 秒时长上限，音频仍须可解码且不超过 20 MiB，请求或合成超时仍会失败。试听通过只代表合成和播放可用，发送还需要对应抖音入口适配、账号状态与网络正常。

没有声音时检查系统引擎语言、API 密钥、已选音色、音频地址字段和返回文件。接口返回 401/403 通常检查鉴权；无音色列表时检查独立地址及 JSON 路径，TXT 列表不要填写 JSON 路径。自动评论的语音连续 3 次明确失败后将完整正文转文本，文本仍由抖音发布校验；自动回复的语音失败不会改发文本。

## 常见问题与检查顺序

### 找不到设置或功能没有生效

1. 核对实际安装的抖音包名、版本和内部构建号，40.8.0 只支持 40809900，不再支持 40809985；40.6.0 适配保留。

2. 在 LSPosed 核对模块已启用、作用域选中抖音，完全结束抖音进程后重新打开。

3. 在模块应用查看框架连接和扫描诊断，在抖音设置中的 DouAi 配置功能。不要把模块应用的诊断当成功能开关。

4. 一次打开一个功能，在它适用的页面触发。若扫描目标未找到、存在多个候选或关系校验失败，该功能可能停用；不会随意选择一个方法继续执行。

5. 启动类开关看下一次启动，推荐过滤看新加载内容，手势看当前推荐视频。版本伪装不能修复版本适配。

### 下载失败或找不到文件

检查启用下载菜单、当前下载方式、分享链接、API 返回状态以及选中的下载字段。接口更换后先更新 GET、测试实际响应，再重新选字段。第三方响应是网页时使用真正接口最终地址；下载解析 GET 不自动跟随重定向。

检查保存目录是否存在且仍获授权，重新选择目录可修复部分权限问题。默认第三方文件在 Download/DouAi 的作品目录中，同时保存信息 TXT。已选第三方时，手势保存也使用第三方，不能靠手势绕开错误的第三方配置。

### 自动回复或评论没有触发

检查“开启自动回复”及对应的接收私聊、接收群聊、接收评论回复子项，或自动评论开关；固定内容是否为空；“回复内容/评论内容 → 模型配置”所选配置是否已保存且仍存在，选择“跟随全局模型”时是否已选择全局默认配置；私聊、群聊或作品范围是否包含目标；关键词与匹配字段是否正确；每日额度和同一 UID 间隔是否达到限制。评论回复需要父开关和接收子项同时开启，不受互动自动化总开关控制。

使用关系名单时先刷新关注与粉丝数据。群聊检查群会话、成员及真实 @ 标记。收到旧消息、自己的消息或不支持的消息类型时不会按新消息自动回复。

评论回复首次开启只建立起点；后续需要抖音处于前台，并且收到可以核实为回复我评论的新回复。纯图片来评需要 AI 模式并开启识别图片，同时取得对方真实附图；无法核实原评论文字或目标关系时跳过。开启保存历史后，进入“自动回复 → 发送与记录 → 回复历史记录”查看带评论回复来源的结果，已提交但结果未确认时不会自动重发。

开启发送历史后区分生成失败、已提交和发送成功，评论记录还显示语音或文本发送方式。开启语音时检查共享语音设置；自动评论连续 3 次语音明确失败后转文本，已提交但结果未确认时不会转文本。

### 模型或第三方接口出错

先用短文字测试，核对完整地址、协议、密钥、模型名称或音色编号。401/403 通常与身份验证或权限相关；429 通常是额度或频率限制；超时需检查网络与服务响应速度。请求头 JSON 的值必须是字符串。

文字通过而图片失败时确认模型支持视觉，再检查素材数量、大小和实际图片请求记录。视频抽样不包含声音，不能通过调整提示词让模型听到未上传的音频。

GET 参数显示来自已保存地址；参数名不对时修改 GET 或参数编辑器，无需刷新参数名。音色刷新用于重新获取音色列表，不用于发现服务商隐藏的参数要求。

### 隐藏后无法操作或发送结果未知

界面按钮消失时先关闭组件隐藏总开关，恢复透明度或删除自定义父容器规则；拍摄+号图标隐藏后原点击区仍可能存在。

发送提示只显示“已提交”或续火花结果未知时，先在会话或评论区核对再重试。停止功能只能取消尚未提交的任务，清空本地历史或记录不会删除已经发送的内容。

报告问题时提供模块版本、抖音实际版本、功能名称、触发页面、相关开关与脱敏错误信息，避免附带完整 API 密钥。

“关于 → 调试与日志”保留功能状态、业务阶段、结果、依据和完整性说明；打开明细可增加诊断摘要。按 trace_id 关联异步操作与重试，提交接受和结果确认分别记录。评论、私信、AI正文与凭据不写日志。页面显示最近 128K 字符，导出包含最多 2 MiB 保留日志和完整性清单；支持刷新、复制和清空。独立模块页面需要抖音正在运行。详见[调试说明](debug-logging.md)及[事件规范](logging-events.md)。


### 音色目录补充（0.2.28）

Breeze 与 Fish 先按标签筛选，目录语言默认中文；每页 20 项、每组筛选最多 200 项。列表内搜索原名、中文译名、ID 和标签；点“搜索全部音色”沿用筛选查询接口。“翻译名称”显式使用已选择的全局默认文字 AI；尚未选择时，先在快捷菜单“切换模型 → 全局默认”选择配置。成功译名本地缓存并保留原名，打开列表不自动翻译。完整规则见 [Breeze](breeze-speech.md) 与 [Fish](fish-speech.md)。
