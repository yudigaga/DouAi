# DouAi 0.2.25 本地正式版：Breeze Blue 与 Fish Audio 语音

版本 **0.2.25 / 126**，包名 `io.github.yudigaga.douai`，沿用长期证书构建签名 Release，启用 R8。本轮为本地构建，未发布 GitHub 或 LSPosed。

## 本次更新

- 文本转语音新增 **Breeze Blue** 和 **Fish Audio**。与 MiniMax 使用相同的模型、音色、接口、朗读、高级设置及试听分组，各来源独立保存 API 地址、密钥、模型、音色、参数和目录缓存。
- Breeze Blue 使用同步完整音频接口，支持模型和账户音色刷新、手填音色、指令、语言、语速、音量、引导强度、说话人增强，以及 MP3/WAV/FLAC/AAC/Opus 输出配置。
- Fish Audio 将 TTS 引擎和参考音色分开选择，支持公开引擎目录刷新、我的/公开音色及标题搜索、接口默认音色、dB 音量、响度归一化、MP3/WAV/Opus、生成分块参数、文本归一化语言和发音字典。引擎使用已支持的官方名称，未知名称拒绝保存，避免服务静默改用默认引擎。
- 手势快捷音色面板支持两家新来源。更换来源或关闭设置会阻止过期回调写入其它来源；目录刷新失败保留原缓存，Fish 搜索窗口受限或分页重复会受控失败。
- 两家设置纳入备份；默认去除 API Key，模型和音色目录缓存不导出。恢复旧密钥受服务地址边界约束，Fish 音频 Token 预算作为普通生成参数保留。

手动 `#` 转语音、自动回复语音和自动评论语音共用所选语音来源，文本 AI 模型的独立选择保持原有行为。新增 HTTP 层不自动重发、不切换供应商，不修改原有评论语音重试和文字回退策略。正文原样送往所选接口；网络来源各自受服务要求约束，Fish 不套用 Breeze 的文本上限。评论继续使用生成的原文件，私聊及群聊沿用既有宿主发送处理。

## 使用入口

进入“扩展功能 → 文本转语音设置 → 语音来源”，选择 Breeze Blue 或 Fish Audio，在“接口设置”填写对应 Key，然后选择模型和音色并试听。

Breeze Blue 需要音色 ID。Fish Audio 的参考音色可留空，使用接口默认音色；Fish 引擎名称填在“模型”，参考音色 ID 填在“音色”。两家高级参数按各自 API 的实际字段和单位显示，裸 PCM 需改选 WAV。

详细配置见 [Breeze Blue](breeze-speech.md)、[Fish Audio](fish-speech.md) 及[内置帮助对应文档](help.md)。
