# DouAi 0.2.26 本地正式版：按各自 API 完善纯 TTS

版本 **0.2.26 / 127**，包名 `io.github.yudigaga.douai`。本轮只整理 Breeze Blue 和 Fish Audio 的文本转语音，分别使用各自的接口、字段、默认值和音色语义；沿用长期证书构建本地 Release，未发布远端。

## Fish Audio

- 将主入口明确为“语音引擎”，直接选择官方支持的五种引擎，移除不能扩展候选的引擎刷新和受限手填。参考音色库独立刷新，只显示已就绪的 TTS 音色，跳过声音转换和未完成模型；筛选不影响原始分页的推进与完整性检查。
- 音色分为单音色、多说话人和参考音频三种模式。多说话人按顺序保存音色 ID，可重复使用同一音色；正文显式使用 `<|speaker:0|>` 等标签，模块不自动改写正文或提示词。S1 的模式约束按 Fish 接口校验。
- 参考音频可导入 WAV、MP3 或 FLAC，并填写样本实际说出的原文。样本以 MessagePack 原始二进制发送，可按说话人分组；本机路径和样本名称不进入请求。读取只允许当前宿主私有导入目录的文件，合计 8 MiB、8 个分组、每组 4 份样本为模块预算，官方 10–30 秒是参考质量建议。
- 本机音频绑定不随普通配置备份导出，备份不能注入文件路径。模式切换保留原有配置；草稿取消、关闭及迟到回调清理未保存的导入文件，已保存素材保留。
- S1 下隐藏并省略无效的响度归一化；关闭文本归一化后隐藏并省略无用途的语言项。其它原生生成参数保留，默认值仍按 Fish 原生 API。

## Breeze Blue

- 新增“自动选择”语音模型，自动模式省略 `model_id`，让 Breeze 按语言选择；已有明确模型配置保持。基础模型与多语言模型分别显示适用的语言选项。
- 可选择同步、HTTP 流式接收或后台任务。后台模式只提交一次生成请求，之后在同一服务地址查询任务状态、下载音频；忽略响应提供的外部下载地址。音频暂未就绪的 `425 / Retry-After` 继续等待同一个任务，不重新生成；整个等待和网络操作受统一截止及取消约束。
- 语音指令可手动点击“优化指令”，只向 Breeze 的专用优化接口发送当前指令草稿。结果预览后仍需保存才生效，正文不会发送给该优化接口，也不会被修改。优化入口的 1000 字符上限不套用于一般指令的保存。
- 按 Breeze 自己的优先级处理说话人增强与引导强度：当前不生效的控件隐藏并说明原因，保存值保留，请求发送实际有效值。
- 音色列表新增全部/官方/个人范围、关键词和语言筛选。目录语言与合成语言独立保存；翻页保持筛选，空搜索结果可正常完成。

## 使用与边界

进入“扩展功能 → 文本转语音设置”，选择对应来源。Fish 的多说话人、参考音频在“音色”中配置；Breeze 的返回方式在高级音频设置中选择，指令优化位于语音指令编辑器。

所有模式都在完整音频取得并通过既有校验后交给发送入口。当前场景已有完整正文，不扩展实时文本输入的 WebSocket、ASR、模型训练或发布管理；纯音频发送不增加无消费者的时间戳设置，也不提供无法直接发送的裸 PCM，需改选 WAV。原有 MiniMax、第三方、系统语音、评论原文件发送和业务重试策略保持。

详细参数与各自官方依据见 [Fish Audio](fish-speech.md)、[Breeze Blue](breeze-speech.md) 和[帮助文档](help.md)。
